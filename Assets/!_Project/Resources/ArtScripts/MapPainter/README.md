# Modular Map Painter

대상 프로젝트: Unity 6000.3.21f1. 작업 Scene: `Assets/!_Project/Scenes/ArtTestScene.unity`.

## 시작

1. ArtTestScene을 엽니다.
2. `Tools > Art > Modular Map Painter`를 선택합니다.
3. 작업 맵이 없으면 **맵 작업 시작**을 누릅니다.
4. **페인트 모드 시작**을 누르고 **바닥** 또는 **경로**를 선택합니다.
5. Scene에서 좌클릭하거나 드래그합니다. Shift는 지우기, Ctrl+Z는 실행 취소입니다.
6. 사각형 영역을 켜면 드래그 시작점부터 끝점까지 채웁니다. 한 작업의 상한은 4096칸입니다.
7. Alt·우클릭·중클릭으로 Scene 카메라를 이동합니다. Esc는 페인트 모드 종료입니다.

## 바닥 자동 선택

- 칸 중앙은 맵 루트 위치에서 X/Z 정수 좌표입니다. 칸 경계는 중앙 ±0.5이며 간격은 1입니다.
- 윗면은 맵 루트의 Y에 맞춥니다. 바닥 모델은 아래쪽으로 두께를 갖습니다.
- 맵 루트의 월드 회전은 0, 월드 스케일은 1이어야 합니다. 위치 이동은 가능합니다.
- 상하좌우에 칸이 없으면 그쪽 변을 경사지게 마감합니다.
- 상하좌우가 이어져 있지만 대각선 칸이 없으면 해당 모서리를 잘라 안쪽 모서리를 마감합니다.
- 원본 FBX의 실제 형상을 조사하여 변·모서리 규칙을 등록합니다. 파일 이름이나 화면 방향으로 추측하지 않습니다.
- 원본의 9개 형태를 우선 사용하며, 나머지 회전 유형은 별도 `AutoFloor_` 보완 메시로 생성합니다. 보완 메시는 원본 박스와 같은 0.025 경사 및 홈 비율을 사용하는 절차적 형상입니다. 원본과 동일한 수작업 메시라고 주장하지 않습니다.
- 가져온 원본의 실제 크기에 맞춰 래퍼 프리팹에 균등 스케일과 피벗 보정을 적용합니다. FBX와 Importer는 수정하지 않습니다.
- 삼각형이 참조하지 않는 정점 때문에 경계가 과대 계산되는 경우, 복사 메시의 Bounds만 실제 사용 정점으로 보정합니다.
- 칠하거나 지우면 주변 8칸도 갱신합니다. 바닥을 지우면 같은 칸의 경로도 지워집니다.

## 경로 기반

- 바닥이 있는 칸에만 경로를 칠할 수 있습니다. 상하좌우로 맞닿은 경로 칸은 연결됩니다. 대각선만 맞닿은 칸은 연결되지 않습니다.
- 단독, 끝점, 직선, 코너, T 분기, 교차를 판별하고 90도 회전으로 연결합니다. 화살표 및 진행 방향은 사용하지 않습니다.
- 아직 경로 모델이 없으면 데이터만 기록하고 Scene에 주황색 연결선을 표시합니다. 이 선은 Game 뷰나 빌드에는 나타나지 않습니다.
- 창의 **경로 모델 등록**에 프리팹을 넣으면 기존 경로 칸에도 실제 모델이 배치됩니다.
- 경로 프리팹은 한 칸의 논리적 중심을 X/Z 원점으로, 박스와 닿는 바닥면을 Y=0으로 제작합니다. 맞닿는 연결면은 해당 방향의 ±0.5 경계에 놓아야 합니다. 루트 스케일은 1입니다.
- 기본 방향: 끝점 +Z, 직선 +Z/-Z, 코너 +Z/+X, T +Z/+X/-X. 방향이 다르면 **회전 보정**을 설정합니다.
- 경로 전체 높이를 추가로 조절하려면 **경로 높이 보정**을 사용합니다.
- 길을 여러 칸씩 빠르게 그려도 중간 칸을 상하좌우로 보간합니다. 경로가 없는 바닥 칸은 건너뛰므로, 먼저 바닥을 채우세요.
- 가까이 붙은 평행 경로도 연결됩니다. 별도 연결 링크로 구분하는 기능은 현재 범위에 없습니다.
- `Resources/Map/Road`의 RoadBase / RoadCorner를 자동 정렬·등록합니다. 직선은 +Z/-Z, 코너는 +Z/+X로 정렬하며, 실제 모델의 열린 면과 표면 높이를 검사합니다.
- 경로 색상은 **안쪽 길**과 **테두리·측면**으로 나눕니다. Scene에서 즉시 미리 볼 수 있으며 맵 프리팹에 저장됩니다.
- 색상 분할 시 원본 FBX의 노멀을 보존합니다. 작은 코너 삼각형의 노멀이 0이 되지 않도록 처리하며, 모델 형상은 변경하지 않습니다.
- `RoadCorner2.fbx`는 열린 면 세 곳을 판별해 T자 분기 모듈로 등록합니다. 세 방향으로 칠한 칸은 자동 회전하며 분기 칸을 지우면 직선/코너로 돌아갑니다. 길 내부/테두리 두 색상, 프리팹 저장, 생성 연출에도 적용됩니다.
- 끝점과 단독 칸은 양쪽이 열린 직선 모델을 사용합니다. 막힌 끝 모양이나 십자 분기는 전용 모델을 추가해야 합니다.

## 프리팹 저장과 재편집

- **ArtPrefabs에 새 프리팹으로 저장**을 누릅니다.
- 저장 경로: `Assets/!_Project/Resources/ArtPrefabs/<이름>.prefab`.
- 설계도 배경의 표시 여부, 색상, 격자 간격과 선 농도도 프리팹에 함께 저장됩니다.
- 이름이 겹치면 숫자를 붙여 새 파일로 저장합니다. 기존 맵 프리팹은 덮어쓰지 않습니다.
- 바닥/경로 오브젝트와 격자 좌표, 팔레트 참조를 함께 저장합니다.
- **불러올 맵 프리팹**을 지정하고 **프리팹에서 편집용 맵 불러오기**를 누르면 Scene에 별도 편집 사본을 만듭니다. 기존 작업 맵을 삭제하지 않습니다.
- 편집 사본은 맵의 최상위 프리팹 연결만 해제하여 재배치가 가능하게 하고, 개별 모델의 프리팹 연결은 유지합니다.
- 프리팹을 직접 Scene에 끌어다 놓은 뒤 작업 맵으로 지정하는 경우에도 첫 편집 때 최상위 맵 연결을 해제합니다.
- 경로 규칙은 공용 모듈 팔레트를 공유합니다. 경로 모델 등록 변경은 같은 팔레트를 사용하는 맵들의 재배치에도 적용됩니다.

## 맵 생성 연출

- **맵 생성 연출 미리보기**로 Scene/Game 화면에서 윤곽선 → 바닥 상승 → 연결 순서대로 길 생성 연출을 확인합니다. **중지 · 원래 맵 복원**은 원래 위치, 크기, 표시 상태와 색상 블록을 복원합니다. 미리보기는 반복할 수 있으며 게임의 재생 여부에 영향을 주지 않습니다.
- 시간, 바닥 상승 높이, 글리치 강도, 윤곽선 색상을 조절합니다. 설정과 윤곽선 머터리얼은 맵 프리팹에 저장됩니다.
- 저장, 창 닫기, 스크립트 재컴파일, Play 전환 때는 미리보기를 종료합니다. 미리보기 중에는 칠하기와 프리팹 저장이 비활성화됩니다.
- 게임에서는 Hierarchy의 활성 맵에 붙은 `MapBuildSequence`가 자동 재생합니다. 같은 입장 중의 재활성화, 같은 맵 프리팹 재생성, 같은 씬 다시 불러오기에는 재생하지 않습니다. 스테이지 선택 씬을 거쳐 입장하면 다시 재생합니다.
- 선택 UI를 같은 씬의 패널로 구현할 때는 새 스테이지 입장 직전에 `MapBuildSequence.BeginStageEntry()`를 호출하고 맵을 생성/활성화하세요. 이미 활성인 맵에는 `sequence.PlayStageEntry()`를 호출합니다. 재도전은 이 함수를 호출하지 않습니다. 선택/입장과 재도전을 일반적인 오브젝트 재활성화만으로 구분할 수 없으므로 같은 씬 UI에서는 이 신호가 필요합니다.
- 현재 기존 `DefenseBattle.Restart()`는 맵을 유지하며 전투 상태를 초기화하므로 연출을 재생하지 않습니다. 해당 원본 스크립트는 수정하지 않았습니다.
- 연출은 `Time.timeScale`과 무관하게 진행됩니다. 외부 게임 흐름과 연결할 때는 `IsAnimating`, `Completed`를 사용할 수 있습니다. 기존 전투 로직이나 입력을 자동으로 멈추지는 않습니다.
- 길은 왼쪽 끝점을 우선으로 연결 순서를 찾으며 분기/분리 경로는 너비 우선으로 처리합니다. 윤곽선은 격자 외곽선이며 모델의 둥근 모서리까지 추출하는 효과는 아닙니다.
- 검증 기록: `Logs/MapPainter/BuildValidation.txt`, 단계별 실제 렌더: `Logs/MapPainter/Build_00.png`부터 `Build_04_Complete.png`까지.

## 설계도 배경

- **설계도 배경**에서 파란 배경과 흰 격자의 색상, 월드 단위 간격, 화면 픽셀 기준 선 굵기를 조절합니다. 작은 격자와 큰 격자의 농도는 따로 조절합니다.
- 배경은 바닥 몸체 아래의 평면이며 조명과 그림자 영향을 받지 않는 URP 쉐이더입니다. Game 카메라는 같은 파란색의 Solid Color를 사용합니다.
- 평면은 현재 Game 카메라 화면을 채우고, 격자는 월드 X/Z 좌표를 기준으로 표시합니다. 화면 비율이나 맵 크기가 바뀌면 배경 크기도 갱신됩니다.
- 카메라를 맵에 맞출 때 배경 평면은 맵 경계에서 제외하므로, 배경 때문에 맵이 작게 잡히지 않습니다.
- 설계도 표시를 끄면 평면을 숨기고 카메라를 기본 어두운 단색으로 되돌립니다.

## 카메라

- 참고 이미지의 격자처럼 가로선을 수평으로 두고 내려다보는 직교 카메라를 사용합니다.
- 초기 각도는 X=55도, Y=0도, Z=0도입니다. 원본 이미지의 정확한 카메라 파라미터가 아니라 참고 구도에 대한 근사입니다.
- **Scene 화면을 참고 각도로 맞추기**는 Scene 뷰만 조정합니다.
- **게임 카메라를 맵 크기에 맞추기**는 ArtTestScene의 MainCamera를 조정합니다. 화면 비율과 맵 크기를 기준으로 여백을 계산합니다.
- 맵을 크게 확장하거나 Game 화면 비율을 변경하면 카메라 맞추기를 다시 누르세요.
- 초기 설치는 ArtTestScene에 편집 루트와 카메라 설정을 반영합니다. 설치 전에 Scene에 미저장 변경이 있었다면 자동 저장하지 않으므로 Ctrl+S로 저장하세요.

## 파일 위치와 검증

- 모든 코드: `Resources/ArtScripts/MapPainter`.
- 팔레트·정렬된 모듈·보완 메시: `Resources/ArtScripts/MapPainter/Generated`.
- 저장된 완성 맵: `Resources/ArtPrefabs`.
- `Tools > Art > Validate Modular Map Painter`는 별도 Preview Scene에서 모델 치수, 규칙, 로컬 갱신, 경로 데이터, 프리팹 저장/복원, 카메라 렌더를 검증합니다. 사용자 Scene의 맵을 시험용으로 칠하지 않습니다.
- 결과는 `Logs/MapPainter/Validation.txt`, 원본 모델 조사 결과는 `Logs/MapPainter/ModelAudit.txt`, 렌더는 `Logs/MapPainter/FloorPreview.png`입니다.
- 실제 마우스 입력과 Ctrl+Z/Ctrl+Y 조작 검증은 별도로 필요합니다.
- Play Mode에서는 편집이 비활성화됩니다. 생성물은 일반 오브젝트이며 런타임 맵 생성기나 Collider 자동 추가 기능은 포함하지 않습니다.

참고 API: [SceneView.duringSceneGui](https://docs.unity3d.com/ScriptReference/SceneView-duringSceneGui.html), [PrefabUtility.InstantiatePrefab](https://docs.unity3d.com/ScriptReference/PrefabUtility.InstantiatePrefab.html), [Undo.RegisterCreatedObjectUndo](https://docs.unity3d.com/ScriptReference/Undo.RegisterCreatedObjectUndo.html).

## 두 단색과 미리보기

- **바닥 색상 · 홈 기준 위 / 아래**에서 **위쪽 판**과 **아래쪽 몸체**를 변경합니다.
- 홈의 가운데(정렬된 1칸 모듈의 Y=-0.2)를 기준으로 색상 영역을 구분합니다.
- 색상을 바꾸면 Scene의 기존 바닥이 즉시 갱신됩니다. 이후 칠하는 바닥에도 같은 색이 적용됩니다. 창 안의 별도 박스 미리보기는 제거했습니다.
- 색상은 맵마다 따로 저장합니다. 공용 머터리얼 에셋의 색을 수정하지 않으므로 다른 맵 색에는 영향을 주지 않습니다. 프리팹 저장 및 재로드 시 두 색을 복원합니다.
- 현재 1슬롯 FBX는 원본을 보존하고 별도 복사 메시의 두 서브메시로 나눕니다. 자동 보완 모듈에도 같은 경계를 적용합니다.
- 향후 3ds Max에서 제작할 때는 Multi/Sub-Object 재질의 Material ID 1을 위쪽 판, ID 2를 아래쪽 몸체에 배정하세요. 서로 다른 이름(예: FloorUpper / FloorLower)의 재질을 사용하고 FBX로 내보냅니다.
- Unity에서 실제 슬롯 순서를 확인하세요. 첫 슬롯이 위쪽, 둘째 슬롯이 아래쪽이어야 합니다. 원본이 2슬롯이면 복사 단계에서 해당 구분을 유지합니다.
- 단색에는 UV Unwrap 수정이 필요 없습니다. 무늬/텍스처를 추가할 때 UV 배치를 따로 검토하면 됩니다.
- 색상은 슬롯별 MaterialPropertyBlock으로 적용하며, 실제 명암은 Scene 조명과 셰이더에 따라 달라집니다.
- 팔레트 이름은 ModularMapPalette, 새 맵/기본 프리팹 이름은 Modular Map / ModularMap입니다. 기존 입력 모델 폴더 이름은 에디터의 적용 스테이지를 제한하지 않습니다.

3ds Max에서 FBX를 다시 내보낸 뒤에는 **원본 FBX 변경 후 바닥 모듈 갱신**을 눌러 복사 메시와 자동 보완 모듈을 다시 만드세요. 색상, 경로 등록과 격자 배치는 유지합니다.

## 크기와 쉐이더

- **한 칸 크기**로 X/Z 간격과 바닥·길의 크기를 함께 조절합니다. 1~8의 정수 단위이며 맵 루트의 Transform Scale은 1로 유지합니다.
- 현재 ArtTestScene은 한 칸 2단위(바닥 약 34×20)로 설정했습니다. 비교용 Cube는 변경하지 않았습니다. 기존 Defense 임시 바닥의 크기는 28×18입니다.
- **바닥 두께**는 X/Z 크기와 독립적으로 조절합니다. 경로는 균일 확대하며, **경로 높이 보정**은 월드 단위입니다.
- 크기 설정을 바꾸면 격자·배치 좌표와 카메라가 함께 갱신됩니다. 크기, 색상과 쉐이더 조절값은 완성 맵 프리팹에 보관됩니다.
- `Shaders/StylizedMapSurface.shader`는 프로젝트의 URP 17.3에 맞춘 단색 쉐이더입니다. **부드러운 명암 / 그림자 농도 / 몸체 아래쪽 음영 / 모서리 밝기**를 맵별로 조절합니다. 기본 셰이더의 그림자·깊이 패스를 함께 사용합니다.
- 참고 이미지의 색감과 부드러운 명암을 위한 기반입니다. 이미지 속 소품·텍스처·환경 조명은 별도 아트 작업입니다.
- 바닥 입력은 `Resources/Map/Floor` 안을 재귀 검색합니다. 현재 사용자가 변경한 경로는 `Map/Floor/Floor`입니다.
- 보완 모듈의 코너는 윗면만 깎고 몸체는 원래 너비로 유지합니다. 생성된 복사 메시의 맞닿는 내부 면을 제거하고 평면 법선을 적용합니다.
- 생성 메시를 덮어쓸 때 Mesh API로 버텍스·UV·인덱스를 설정하고 GPU에 업로드합니다. 이전 버전의 CopySerialized 방식에서 생긴 옆면 표시 오류를 방지합니다. 원본 FBX는 수정하지 않습니다.
