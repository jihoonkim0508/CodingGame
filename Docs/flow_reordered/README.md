각 로봇의 공격 프로그램은 몬스터별로 1회 실행한다. 실행을 마친 대상은 자동으로 다시 공격하지 않으며, 새로운 몬스터가 나타나면 코드를 처음부터 실행한다. 같은 몬스터 추가 공격은 for/while 등 작성한 명령으로 제어한다. 반복 안에서 적 찾기를 다시 호출해도 이번 실행의 대상을 유지한다. 반복과 현재 프로그램을 마친 뒤 다음 몬스터를 선택한다. 대상이 먼저 죽으면 남은 반복의 공격을 건너뛰며 다른 적에게 피해를 넘기지 않는다. 조건문은 반복문이 아니다. 이 게임은 행동하지 않은 프로그램을 일정 시간 후 재평가한다. for 안에서는 거짓 조건으로 건너뛴 회차도 반복 횟수에 포함된다.

원거리 사격의 기존 거리별 피해 규칙을 사용한다. 2-3 미리보기는 같은 레벨, 같은 적, 같은 경로로 비교하며 '조건 없음 / 거리 3 이하'의 실제 피해를 표시한다. 너무 작은 거리 기준이나 길에서 먼 배치는 공격 기회를 없앨 수 있다.
