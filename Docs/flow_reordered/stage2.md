[2-1.B02] 안내자 : 이번에는 반복문과 적 찾기를 준비했어.\n<b>for 안에서 적을 찾고 → 그 적을 공격</b>하는 흐름은 전사와 같아!

[2-1.B05] 안내자 : 이름을 <b>enemy</b>로 바꾸자.\n바로 위에서 찾아 둔 적에게 탄을 쏘는 거야!

[2-1.C01] 안내자 : 코드는 자동으로 적용돼. 왼쪽을 봐!\n원거리 로봇이 적을 향해 탄을 쏘고 있어.

[2-1.C02] 안내자 : <b>탄이 적에게 도착해서 체력이 줄었어!</b>\n길에서 떨어진 이 자리에서도 공격이 닿는 거야.

[2-1.C03] 안내자 : 원거리는 멀리 닿지만 <b>가까운 적일수록 피해가 커져.</b>\n우선 반복 사격을 익히고, 뒤에서 조건문으로 사격 시점을 바꿔 볼 거야.

[2-1.D01] 안내자 : 이제 전사와 원거리 로봇이 함께 싸워 볼 차례야.\n<b>‘전투 시작’</b>을 눌러 봐!

[2-1.D01a] 안내자 : 이제 전사와 원거리 로봇이 함께 싸워 볼 차례야.\n<b>‘전투 시작’</b>을 눌러 봐!

[2-1.D02] 안내자 : 이번 웨이브를 마쳤어!\n원거리 로봇은 <b>더 멀리 닿는 사격</b>을 쓸 수 있어. 공격 범위를 보고 자리를 정해 주자!

[2-1.D03] 안내자 : 다음에는 원거리 로봇의 위치와 코드를 네가 직접 정해 보자.\n<b>‘보상 수령’</b>을 눌러 줘!

## 2-2 — 원거리 반복 사격 자유 실습

[2-2.A01] 안내자 : 이번에는 <b>원거리 로봇을 활용해서 기지를 지켜 보자!</b>\n기존 로봇과 코드는 그대로 남아 있어.

[2-2.A02] 안내자 : 이미 배치한 원거리 로봇의 위치와 반복 횟수를 조정해 보자.\n반복 중에는 같은 몬스터를 공격하고, 반복이 끝나면 다음 몬스터를 찾아.

[2-2.A03] 안내자 : 원거리 로봇의 <b>적 찾기 → 사격</b>을 반복하도록 만들어 줘. 준비되면 전투를 시작해!

[2-2.B01] 안내자 : 이번 웨이브를 마쳤어!\n원거리 로봇도 <b>적 찾기 → 공격하기</b>를 반복하도록 만들었어.

[2-2.B02] 안내자 : 다음에는 사격 시점을 바꿔 볼 거야.

[2-2.B04] 안내자 : 보상을 받고 조건문 실습으로 가자.

## 2-3 — 조건문 소개: 가까울 때 더 강하게 사격

[2-3.A01] 안내자 : 반복문은 <b>몇 번 할지</b> 정해 줬지. 이번에는 <b>어떤 상황에서 할지</b> 정해 보자.

[2-3.A02] 안내자 : 원거리 공격은 가까울수록 강해져.\n조건문으로 <b>적이 거리 3 안에 들어왔을 때만 사격</b>하게 만들 거야.

[2-3.P01] 안내자 : 비교 실습용 원거리 로봇을 새로 놓아 줘.\n적이 지나는 길에서 <b>거리 3보다 가까운 곳</b>에 놓아야 조건이 참이 될 수 있어.

[2-3.A03] 안내자 : 방금 놓은 <b>원거리 로봇</b>을 눌러 봐.

[2-3.A04] 안내자 : 개발을 열고, 조건 없는 사격과 조건을 넣은 사격을 비교해 보자.

[2-3.A05] 안내자 : 먼저 조건 없는 사격이야.\n적이 사거리 끝에 들어오자 바로 쏘지? <b>피해 숫자</b>를 기억해 둬.

[2-3.B01] 안내자 : 첫째 줄은 익숙하지?\n적을 찾아 <b>enemy라는 이름으로 기억</b>하는 코드야.

[2-3.B02] 안내자 : 둘째 줄은 <b>적과 로봇 사이의 거리</b>를 재서 enemy_distance에 저장해.\n이름이 길지만, 지금은 ‘적까지의 거리’라고 읽으면 돼!

[2-3.B03] 안내자 : 원거리 로봇의 전체 사거리는 3보다 길어.\n이번에는 공격할 수 있어도 기다렸다가 <b>거리 3 안에서 사격</b>할 거야.

[2-3.B04] 안내자 : 조건은 <b>적까지의 거리 ≤ 3</b>이야.\n3보다 멀면 사격을 건너뛰고, 가까워지면 사격해.

[2-3.B05] 안내자 : ≤는 작거나 같다는 뜻이야.\n거리 3.1은 거짓, 거리 3이나 2는 참이야.

[2-3.C01] 안내자 : 먼저 <b>if 블록</b>을 두 줄 아래에 놓아 줘.\nif는 ‘만약 ~라면’이라는 뜻이야.

[2-3.C03] 안내자 : if 옆에는 <b>‘어떤 때에 행동할지’</b>를 넣어야 해.\n가운데의 <b>비교 블록</b>을 눌러 넣어 줘.

[2-3.C04] 안내자 : 비교 기호를 <b><=</b>로 바꿔 줘.\n적까지의 거리가 정한 숫자 이하인지 확인할 거야.

[2-3.C06] 안내자 : 비교 블록의 왼쪽에는 <b>적까지의 거리</b>를 넣자.\n등호 없는 <b>variable 블록</b>을 눌러 줘.

[2-3.C07] 안내자 : 넣은 블록의 글자를 눌러 <b>enemy_distance</b>로 바꿔 줘.\n둘째 줄에서 거리를 저장한 이름과 같아야 해!

[2-3.C09] 안내자 : 비교 오른쪽 빈칸에 <b>숫자 블록</b>을 넣어 줘.

[2-3.C09a] 안내자 : 숫자 칸을 눌러 <b>3</b>으로 바꿔 줘.\n이 숫자가 사격을 시작할 거리야.

[2-3.C10] 안내자 : 조건을 읽어 보자.\n<b>적까지의 거리가 3 이하라면!</b> 참일 때만 안쪽 명령을 실행해.

[2-3.D02] 안내자 : 조건이 맞을 때 할 행동은 <b>사격 attack</b>이야.\n사격 블록을 if 안쪽에 넣어 줘.

[2-3.D04] 안내자 : 사격 대상 빈칸에 <b>variable</b> 블록을 넣어 줘.

[2-3.D05] 안내자 : 넣은 블록의 글자를 <b>enemy</b>로 바꿔 줘.\n첫째 줄에서 찾아 둔 적을 공격하는 거야!

[2-3.D06] 안내자 : 이번에는 같은 적이 더 가까워진 뒤 사격했어!\n<b>앞서 본 피해 숫자보다 커졌는지</b> 비교해 봐.

[2-3.D07] 안내자 : 조건이 없으면 사거리 끝에서 바로 사격해.\n<b>거리 조건을 넣으면 더 가까워질 때까지 기다려 강하게 사격</b>할 수 있어. 너무 작은 거리는 적이 지나가는 길에 닿지 않을 수도 있어.

[2-3.E01] 안내자 : 이번에는 <b>몬스터마다 조건을 만족할 때 한 번 사격</b>해 볼 거야.\n같은 몬스터에게 반복해서 조건 사격하는 실습은 다음에 하자.

[2-3.E02] 안내자 : 전투를 시작해 봐. 적이 <b>거리 3 안에 왔을 때</b> 사격하는지 지켜보자!

[2-3.E03] 안내자 : 거리 조건이 참이 되어 사격했어!

[2-3.E04] 안내자 : 조건문으로 <b>공격할 수 있는 때 중에서도 원하는 시점</b>을 골랐어.

[2-3.E05] 안내자 : if는 조건을 확인하는 명령이야.\n이번 게임은 행동을 하지 않은 코드를 다시 확인해 줘. <b>if 자체가 반복문은 아니야.</b>

[2-3.E06] 안내자 : 다음에는 for 안에서 매번 거리를 확인하고 사격해 보자. 보상을 받아 줘!

## 2-4 — 반복과 조건: 매번 거리를 확인하고 사격

[2-4.A01] 안내자 : 이번에는 <b>반복문 안에 조건문</b>을 넣어 보자. 같은 대상의 거리를 매번 확인하고 사격하는 거야.

[2-4.A02] 안내자 : 새 원거리 로봇을 길 가까이에 놓아 줘.\n조건으로 정한 거리 안에 길이 들어와야 공격할 수 있어.

[2-4.A03] 안내자 : for 안에 <b>적 찾기 → 거리 저장 → if → 사격</b>을 넣어 줘.\n조건이 거짓인 회차도 반복 횟수에 포함돼. 횟수와 배치를 함께 조정해 봐.

[2-4.B01] 안내자 : 같은 몬스터의 거리를 반복해서 확인하고 사격하는 코드를 만들었어!\n이 대상의 반복을 마치면 다음 몬스터에게 새로 실행해.

[2-4.B02] 시스템 : 강력한 오류 코드 반응 감지!

[2-4.B03] 안내자 : 다음에는 보스가 기다리고 있어.\n지금까지 배운 명령과 두 로봇을 함께 활용해 보자!

[2-4.B04] 안내자 : <b>‘보상 수령’</b>을 눌러 마지막 웨이브로 가자.
