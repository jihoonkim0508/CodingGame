# Stage 1 대사 (현재 게임에 들어간 대사)

출처: [tutorial_stage1_대본.md](../flow_stage1/tutorial_stage1_대본.md)(튜토리얼 asset을 만드는 원본, 2026-11-12 대사 수정 반영). 양식은 그 문서와 같다.
대사는 섹션마다 코드 블록으로 감싼다(`<b>`·`\n`이 그대로 보이게). 대사 ID는 에디터·개발 빌드의 대화창 오른쪽 위에 나오는 ID와 같고, F1 개발자 패널에서 이 ID로 이동할 수 있다.

## 읽는 법

- `발화자 : 대사` 형식. 왼쪽이 발화자이며, 구현에서는 **대화창 하나(대사 한 줄)마다 발화자를 입력**한다(고정 이름 없음).
- 발화자가 `시스템`인 줄은 대화창이 아니라 UI(배너)로 표시한다.
- `집중`·`상호작용`·`추가 효과`·`코드`는 대사가 아니라 연출·진행 메모다.
- `▶` 줄: 구현 메모(진행 신호, 판정 조건). 기획 문장이 아니다.

## 1-2

```text
[반복을 활용하는 자유 플레이]
[1-2.A01] 디버 : 이번엔 네가 직접 막아 볼 차례야!\n<b>적이 원 안에 오면 ‘실행’</b>, 기억하지?
[1-2.A02] 디버 : 새 <b>전사형</b> 로봇을 받았어. 길 옆에 세우고\n<b>‘개발’</b>에서 명령을 넣어 줘.
[1-2.A03] 디버 : slash()를 여러 줄 넣으면 한 번에 여러 번 벨 수 있어.\n막히면 <b>‘힌트’</b>, 준비되면 <b>‘전투 시작’</b>!
▶ 여기서 대화창을 숨기고 자유 플레이. 편집기 열기·닫기, 베기 줄 수, 배치, 실행 버튼, 전투 시작을 강제 순서나 정답 코드로 제한하지 않는다.
▶ 기존 코드를 강제로 지우지 않는다. 선택형 힌트는 slash() 한 줄.

[1-2.B01] 디버 : 해냈다! 혼자서도 막아 냈어!
▶ WaveCleared까지 대기. 피해가 있어도 사실인 표현 사용.
[1-2.B02] 디버 : 그런데 매번 누르기 힘들지?\n다음엔 로봇이 <b>알아서</b> 베게 해 보자!
[1-2.B03] 디버 : <b>‘보상 수령’</b>을 눌러 챙기자!
```

## 1-3 — 반복문

```text
[1s- 3w| 반복문: 실행 한 번에 여러 번]

[1-3.C04] 디버 : 반복문 블록은 <b>‘제어’</b> 칸에 있어.\n<b>‘제어’</b>를 눌러 줘!

[1-3.C10] 디버 : 이렇게 명령을 되풀이하는 걸 <b>반복문</b>이라고 해.\n이제 함수가 한 번만 불려도 <b>계속</b> 베!

▶ 반복 줄과 미리보기 강조.
[1-3.D02] 시스템 : 오류 코드 접근 중! 코어 방어 준비!
▶ 편집기 닫기.
[1-3.E01] 디버 : 다른 전사도 반복문으로 바꿔도 좋아.\n준비되면 <b>‘전투 시작’</b>!
▶ 여기서 대화창을 숨기고 자유 진행. 선택형 힌트는 while True: / slash().
[1-3.B01] 디버 : 해냈다! 반복문 덕분에 훨씬 편했지?
▶ WaveCleared까지 대기.
[1-3.B03] 디버 : <b>‘보상 수령’</b>을 눌러 챙기자!
```
