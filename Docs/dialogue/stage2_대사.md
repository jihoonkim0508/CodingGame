# Stage 2 대사 (2-1 ~ 2-10)

출처: [tutorial_stage1_대본.md](../flow_stage1/tutorial_stage1_대본.md)(튜토리얼 asset을 만드는 원본, 2026-11-12 대사 수정 반영). 양식은 그 문서와 같다.
대사는 섹션마다 코드 블록으로 감싼다(`<b>`·`\n`이 그대로 보이게). 대사 ID는 에디터·개발 빌드의 대화창 오른쪽 위에 나오는 ID와 같고, F1 개발자 패널에서 이 ID로 이동할 수 있다.

## 읽는 법

- `발화자 : 대사` 형식. 왼쪽이 발화자이며, 구현에서는 **대화창 하나(대사 한 줄)마다 발화자를 입력**한다(고정 이름 없음).
- 발화자가 `시스템`인 줄은 대화창이 아니라 UI(배너)로 표시한다.
- `집중`·`상호작용`·`추가 효과`·`코드`는 대사가 아니라 연출·진행 메모다.
- `▶` 줄: 구현 메모(진행 신호, 판정 조건). 기획 문장이 아니다.

## 2-3 — 조건문: 벨 때를 고르기 (전사형, 2026-11-18 게임 논리 검토 반영)

원거리 피해가 거리와 무관해져(381f7a9) "거리 3 안에서 쏘기"는 근거가 없다. 사거리 밖 shoot()은 재사용 대기를 쓰지 않지만 slash()는 허공을 베어도 1.6초를 쉰다(DefenseSimulation). 그래서 조건문은 전사형의 "들어왔을 때만 베기"로 가르친다.

```text
[2s- 3w| 조건문: 벨 때를 고르기]
[2-3.A01] 디버 : 전사형은 적이 없어도 <b>slash()</b>를 부르면\n허공을 베고 <b>잠깐 쉬어야</b> 해.
[2-3.A03] 디버 : <b>화살표가 가리키는 전사형 로봇</b>을 눌러 줘!
[2-3.A04] 디버 : <b>‘개발’</b>을 눌러 줘!
[2-3.A05] 디버 : 왼쪽을 봐. 지금 명령은\n적이 오든 말든 <b>계속 베.</b>
▶ 비교용 코드(while True: / slash())를 전사형에 준비하고 미리보기를 처음부터 재생한다. 적 1명이 사거리 밖에서 걸어온다. 허공을 베고 쉬는 사이 적이 사거리를 지나가는 장면까지 보여 주고 진행.

[변수: 가장 가까운 적을 상자에 담기]
[2-3.B01] 디버 : 봤지? 허공을 베고 쉬는 사이\n적이 <b>공격 범위를 지나가 버렸어!</b>
[2-3.B02] 디버 : 코드를 살짝 바꿔 놨어. 첫째 줄은 2-1처럼\n<b>가장 가까운 적</b>을 enemy 상자에 담아.
▶ 이 단계에서 전사형의 프로그램을 while True 안의 적 찾기 한 줄로 준비한다. 조건문과 베기는 플레이어가 조립한다.
[2-3.B04] 디버 : 그래서 이걸 확인할 거야.\n<b>적까지의 거리가 공격 범위보다 작거나 같다면!</b>
[2-3.B05] 디버 : 이 질문의 답은 <b>참</b> 아니면 <b>거짓</b>.\n로봇은 참일 때만 베게 될 거야.

[조건을 한 칸씩 조립하기]
[2-3.C01] 디버 : 조건은 <b>if</b>(만약 ~라면) 블록으로 만들어.\n<b>if</b>를 enemy 줄 바로 아래에 놓아 줘!
[2-3.C03] 디버 : if 옆 빈칸엔 비교가 들어가.\n가운데의 <b>비교 블록</b>을 눌러 넣어 줘.
[2-3.C04] 디버 : 가운데 기호 칸을 눌러\n<b><=</b>(작거나 같다)로 바꿔 줘!
[2-3.C06] 디버 : 왼쪽 칸엔 적까지의 거리가 들어가.\n값 탭의 <b>enemy.distance()</b> 블록을 눌러 줘.
[2-3.C07] 디버 : 괄호엔 내 위치, <b>get_my_pos()</b>를 넣어 줘!
[2-3.C09] 디버 : 오른쪽엔 공격 범위! 값 탭의\n<b>my_attack_range()</b> 블록을 눌러 줘.
[2-3.C10] 디버 : 완성! 거리가 공격 범위 안이면 <b>참</b>,\n참일 때만 if 안쪽을 실행해.
▶ 조건 블록은 처음부터 if의 조건 칸에 조립한다.

[조건이 맞을 때의 행동]

[2-3.D06] 디버 : 첫 조건문 완성! 왼쪽을 봐.\n이번엔 적이 들어올 때까지 기다렸다 벨 거야.
▶ 완성 코드 일치 뒤 미리보기를 처음부터 재생. 실제 명중을 확인한 뒤 진행.
[2-3.D07] 디버 : 봤지? <b>들어오자마자 벴어!</b>\n<b>참이면 if 안쪽을 실행하고, 거짓이면 건너뛰어.</b>

[실전과 복습]
[2-3.E01] 디버 : 이제 진짜 오류 코드에 써 보자!
▶ 편집기를 닫고 전투 준비.
[2-3.E02] 디버 : <b>‘전투 시작’</b>을 눌러 줘!
[2-3.E03] 디버 : 벴다! 적이 공격 범위에 들어온 순간\n조건이 <b>참</b>이 됐어!
```

## 2-6 — `break`: 사거리를 벗어나면 놓아주기 (2026-11-18 게임 논리 검토 반영)

2-5 코드는 노리던 적이 살아서 사거리를 벗어나면 막힌다(is_dead()가 거짓인 채 shoot은 사거리 밖이라 아무것도 쏘지 못한다). 두 겹 반복과 break는 이걸 푸는 법으로 가르친다.

```text
[2s- 6w| break: 안쪽 반복 끝내기]
[2-6.A01] 시스템 : 빠른 오류 코드가 접근 중입니다!
[2-6.A02] 디버 : 이번엔 빠른 녀석이 와. 노리던 적이 살아서\n<b>사거리 밖</b>으로 빠져나가면 어떻게 될까?
[2-6.A03] 디버 : <b>화살표가 가리키는 원거리 로봇</b>을 눌러 줘!
[2-6.A04] 디버 : <b>‘개발’</b>을 눌러 줘!
▶ 원거리 로봇에 준비 코드: while True: / enemy = get_nearest_enemy() / while True: / shoot(enemy). 미리보기를 처음부터 재생, 노리던 적이 사거리를 벗어난 뒤 3초 보여 주고 진행.
[2-6.B01] 디버 : 봤지? 바깥 반복이 적을 담고 <b>안쪽 반복</b>이 그 적만 쏘는데,\n그 적이 멀어져도 <b>계속 그 적만 노려!</b>
[2-6.B02] 디버 : 멀어진 적은 놓아주고 안쪽 반복을 끝내야 해.\n그때 쓰는 게 <b>break</b>야.
[2-6.B03] 디버 : <b>break</b>는 지금 있는 반복 하나를 끝내고\n바로 바깥으로 나가. 바깥 반복은 새 적을 담지!
[2-6.C01] 디버 : <b>if</b> 블록을 안쪽 반복의 첫 줄에 놓아 줘!
[2-6.C02] 디버 : 조건 칸에 <b>비교 블록</b>을 넣고\n가운데 기호를 <b>></b>(크다)로 바꿔 줘.
[2-6.C03] 디버 : 왼쪽 칸엔 <b>enemy.distance(get_my_pos())</b>,\n오른쪽 칸엔 <b>my_attack_range()</b>를 넣어 줘!
[2-6.C04] 디버 : if 안쪽에 <b>‘break’</b> 블록을 넣어 줘!
▶ 정답: while True: / enemy = get_nearest_enemy() / while True: / if enemy.distance(get_my_pos()) > my_attack_range(): / break / shoot(enemy).
[2-6.D01] 디버 : 완성! 왼쪽을 봐.\n적이 멀어지면 break로 나가서 새 적을 찾을 거야.
▶ 미리보기를 처음부터 재생, 새 적에게 명중한 뒤 진행.
[2-6.D02] 디버 : 봤지? <b>break</b>로 안쪽만 끝내고\n바깥 반복이 새 적을 담았어!
[2-6.E01] 디버 : <b>‘전투 시작’</b>을 눌러 줘!
▶ 편집기를 닫고 전투 준비. 선택형 힌트는 정답 여섯 줄.
[2-6.E02] 디버 : 해냈다! 두 겹 반복과 <b>break</b>, 완벽해!
▶ WaveCleared까지 대기.
[2-6.E03] 디버 : <b>‘보상 수령’</b>을 눌러 챙기자!
```

## 2-7 — 자유 실습: 쓰러지거나 멀어지면 break

```text
[2-7.A01] 시스템 : 오류 코드 무리가 다시 접근 중입니다!
```

## 2-8 — `continue`와 `enemy.type`: 단단한 적이 올 때만 쏘기

```text
[2s- 8w| continue: 이번 회차 건너뛰기]
[2-8.A01] 시스템 : 단단한 오류 코드가 섞여 접근 중입니다!
[2-8.A02] 디버 : 단단한 적이 섞여 와! 작은 녀석은 <b>전사형 몫</b>,\n원거리 로봇은 <b>단단한 적이 왔을 때만</b> 쏘자.
[2-8.A03] 디버 : <b>화살표가 가리키는 원거리 로봇</b>을 눌러 줘!
[2-8.A04] 디버 : <b>‘개발’</b>을 눌러 줘!
▶ 원거리 로봇에 2-7 힌트 코드를 준비한다. 미리보기는 재생하지 않는다. 전사형 한 대가 길 옆에 미리 서 있어 작은 적을 맡는다.
[2-8.B01] 디버 : 적에겐 <b>종류</b>가 있어. <b>enemy.type</b>으로 알 수 있지.\n단단한 적은 <b>Enemy.Tank</b>야.
[2-8.B02] 디버 : 가장 가까운 적이 단단한 적이 <b>아니면</b>,\n쏘지 말고 <b>다음 회차</b>로 넘어가 다시 보는 거야.
[2-8.B03] 디버 : 그때 쓰는 게 <b>continue</b>야. 반복의 남은 줄을 건너뛰고\n<b>처음으로 돌아가</b> 다시 시작해!
[2-8.C01] 디버 : <b>if</b> 블록을 적을 담는 줄 바로 아래에 놓아 줘!
[2-8.C02] 디버 : 조건 칸에 <b>비교 블록</b>을 넣고\n가운데 기호를 <b>!=</b>(같지 않다)로 바꿔 줘.
[2-8.C03] 디버 : 왼쪽 칸엔 <b>enemy</b>를 넣고\n점(.)을 눌러 <b>type</b>을 골라 줘!
[2-8.C04] 디버 : 오른쪽 칸엔 값 탭의 <b>‘Enemy.’</b> 블록을 넣고\n<b>Tank</b>를 골라 줘.
[2-8.C05] 디버 : if 안쪽에 <b>‘continue’</b> 블록을 넣어 줘!
▶ 정답: while True: / enemy = get_nearest_enemy() / if enemy.type != Enemy.Tank: / continue / while True: / if enemy.is_dead(): / break / if enemy.distance(get_my_pos()) > my_attack_range(): / break / shoot(enemy). get_nearest_enemy()는 가장 가까운 한 마리만 주므로 이 코드는 단단한 적을 "찾지" 않고, 단단한 적이 가장 가까워질 때까지 기다린다(그동안 작은 적은 전사형이 맡는다). continue 회전이 틱당 스텝 한도에 걸려 멈추거나 Fault가 나지 않는지 확인한다.
[2-8.D01] 디버 : 완성! 왼쪽을 봐.\n작은 적은 넘기고, 단단한 적이 오면 그때 쏠 거야.
▶ 미리보기를 처음부터 재생(작은 적 다음 단단한 적), 단단한 적에게 명중한 뒤 진행.
[2-8.D02] 디버 : 봤지? <b>break</b>는 반복을 끝내고,\n<b>continue</b>는 이번 회차만 건너뛰어!

[2-8.E02] 디버 : 해냈다! 원거리 로봇은 단단한 적을,\n전사형은 작은 적을 맡았어!
```
