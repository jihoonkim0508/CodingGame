## 2. 게임 규칙 (튜토리얼이 기대는 사양)

| # | 규칙 | 구현 상태 |
|---|---|---|
| R1 | 플레이어는 블록 편집기로만 코드를 만든다(타이핑 없음) | 기존 |
| R2 | 로봇 함수 `f`는 웨이브마다 `for i in range(5): f()`처럼 5번 실행된다. 반복문(`for`/`while`) 해금 후에는 1번만 실행된다. 모든 스테이지 동일 | **완료** |
| R3 | 공격 횟수 한도는 없다. 함수 안에 공격 명령을 몇 개든 넣을 수 있다 | **완료** |
| R4 | 웨이브가 바뀌어도 로봇·코드는 유지된다. 스테이지가 바뀔 때만 초기화된다. 한 스테이지 안에서 맵은 같다 | 기존 |
| R5 | 웨이브 통과 = 기지가 살아 있음. 1-1·1-2는 지지 않도록 설계(의도) | 기존 |
| R6 | 1-1·1-2 적: 오류 코드 각 2마리(체력 18 / 약 21, 기지 도달 시 기지 -1, 기지 체력 12) | **완료** |
| R7 | 거리 단위: 1 grid = 1, 맵 한 블록 = 2. 시뮬레이션 좌표 = 월드 XZ | 기존 |
| R8 | 거리 코드: `enemy.distance(get_my_pos())`. `get_my_pos()`는 `Vector2` 객체 반환, `distance`는 float 반환 | 미구현 |
| R9 | `enemy.hp`는 읽기 전용 프로퍼티(괄호 없음) | 기존 |
| R10 | 1-1·1-2 동안 로봇 회수 불가(버튼 비활성, "회수는 1-3부터 열립니다") | **완료** |
| R11 | 레벨업은 1-2부터 가능 | 기존 |
| R12 | 미리보기: 실행 횟수 무제한, 로봇 공격 사거리 원 표시, 적이 모두 사라지면 1초 후 재시작 | **완료** |
| R13 | 게임은 타이틀 화면부터 시작 | 기존 |

R6 근거: 전사 피해 14 → 적 1마리에 베기 2번, 2마리 = 4번 ≤ 함수 5회.

## 3. 대사 표시

| 항목 | 사양 |
|---|---|
| 형식 | `발화자 : 대사`. 발화자는 대화창 하나(대사 한 줄)마다 데이터에 입력 |
| 시스템 대사 | 발화자가 `시스템`이면 대화창 대신 경고 UI(화면 배너 + 경고음, 약 1.5초 후 자동 진행) |
| 코드 강조 | 대사 안 함수·변수 이름은 강조색 |
| 줄바꿈 | 대사의 `\n`은 대화창 줄바꿈 |
| 넘기기 | 이전/다음 버튼. 행동을 기다리는 대사에서는 행동을 마칠 때까지 다음 잠금 |
| 타이핑 | 처음 보는 대사만 타이핑 연출, 다시 볼 때는 즉시 표시. 다음 버튼으로 타이핑 건너뛰기 |
| 전투 중 대사 | 전투를 멈추지 않는다 |
| 그 밖의 대사 | 표시 중에는 전투 일시정지 |

### 프로그램 일치 판정

교육 로봇 프로그램의 Python 미리보기에서 함수 머리줄을 빼고, 각 줄의 들여쓰기·앞뒤 공백을 지운 결과가 정답 문자열과 같으면 일치. 변수 이름이 `enemy`가 아니면 불일치.
교육 로봇 = 이 스테이지에서 처음 배치한 전사형 로봇.

## 6. 예외 처리

| 상황 | 동작 |
|---|---|
| 행동 대상이 사라짐(예: 대상 UI 비활성) | 오류 기록 후 튜토리얼 종료, 입력 제한 해제 |
| 편집기가 닫히거나 로봇 선택이 풀림(대사 단계) | 튜토리얼 유지. 대상 소실 검사는 행동을 기다리는 단계에만 적용 |
| 개발 에디터에서 `tutorial` 옵션 끔 | 튜토리얼 즉시 종료 |
| 개발 에디터에서 `tutorialInput` 옵션 끔 | 대사는 나오고 입력 제한만 해제 |
| 다시 시작(재시작 버튼) | 세션이 바뀌므로 해당 웨이브 튜토리얼을 처음부터 다시 시작 |
