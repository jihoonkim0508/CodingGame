# 비주얼 레퍼런스와 적용 사양 (길 화살표 · 글자 · 선택 강조 · 코드 블록)

6차 백로그 61(길 화살표), 62(선택 강조), 63(코드 블록), 64(글자 전체)의 조사 결과. 작성 2026-11-05. 기준은 1920×1080 캔버스 px. 대비값은 WCAG 2.x 상대휘도 공식으로 계산했고, 화면 색은 `TestResults/Editor/tour/` 스크린샷에서 뽑았다.

쓴 실측 색: 도로 #FFF0BA, 나무 바닥 #ECB36D, 배경 #4B8BBC, 현재 화살표 #92DCF7, 탭 미선택 #F2E8D4, 탭 선택 #F0CC85, for 블록 #1694C7, slash #CC4266, 값 슬롯 #5A3828.

한계: Game UI Database는 접근이 막혔다(403). 쿠키런 킹덤·브롤스타즈·메이플M·카트러쉬·Kingdom Rush 화살표·Bloons·Code.org·MakeCode·Tynker·Swift Playgrounds·Lightbot·CodeCombat의 수치는 공개 자료를 찾지 못해 '관례'로만 적었다. TMP 두께 근사식은 셰이더 식을 읽고 낸 값이라 화면에서 확인해야 한다. Arknights·r/defold 링크는 검색 요약 기준이다.

## 1. 길 방향 화살표

### 현재 진단 (`TutorialPointer.cs` ShowPath)

- 10개 묶음이 300px/s로 지나간 뒤 0.35초 쉰다. 1-1 경로(약 2,400px)면 한 바퀴가 약 10초라 화면 대부분이 대부분의 시간 동안 비어 있다. '느리다'는 체감의 원인이다.
- 모양이 외곽선 없는 꽉 찬 삼각형이라 재생 버튼처럼 읽힌다.
- 하늘색과 도로의 대비가 1.33:1이다(WCAG 1.4.11 기준 3:1).
- 꺾이는 곳에서 방향이 90°로 툭 바뀐다.

- 폰트 쓰는 곳: Jalnan2는 12자 이하 라벨과 숫자 HUD(웨이브 1/5, 코어 12/12, 스테이지 2-1). 문장이 하나라도 있거나 코드 이름이 섞이면 Pretendard.
- 숫자: 값은 라벨보다 1.15배, 라벨은 Muted. 타이머·카운터는 `<mspace=0.6em>`. 코인 색은 #A35C00(4.87:1).
- 3D 위 글자: 32px 이하는 칩(Paper 92% + Ink 3px) 위에. 40px 이상 디스플레이만 외곽선 + 언더레이 프리셋.
- TMP 공유 머티리얼 프리셋(`fontSharedMaterial`):
  - `Jalnan2 SDF - Banner`: Face Dilate 0.15, Outline Ink W 0.55, Underlay Ink α1 Offset (0, −0.45) Dilate 0.55 Softness 0.
  - `Jalnan2 SDF - Title`: Outline 0, Underlay Ink α0.9 Offset (0, −0.6) Dilate 0.2.
  - `Pretendard Bold SDF - Plain`: 효과 없음.
- 두께 근사(화면 확인 필요): 외곽선 총 두께(px) ≈ `W × 10 × 표시크기 / 90`, 바깥은 그 절반(112px에서 W 0.55 → 바깥 약 3.4px, 지금 .18 → 약 1.1px). 언더레이 Offset 1 ≈ `10 × 표시크기 / 90` px. 외곽선 + 드롭이 패딩의 80%를 넘으면 글리프가 잘리니, 더 두껍게 하려면 배너 전용 에셋을 패딩 14–16으로 새로 만든다.

피할 것: 스크립트에서 텍스트마다 `outlineWidth`·`outlineColor` 설정(`DefensePlayerHUD.cs` 289/337/468/604, `DefenseAttackPreview.cs:139`; 머티리얼 인스턴스가 생겨 배칭이 깨진다), 밝은 배경 위 Sunny·Primary 글자, 본문 Jalnan2, 18px 미만, Pretendard Bold 에셋에 FontStyles.Bold 중복, 본문 음수 자간, 3D 위 맨 본문.

## 3. 선택 상태 강조 ('제어' 탭)

### 현재 진단 (`CommandCodingPanel.cs:116`)

선택 #F0CC85와 미선택 #F2E8D4의 대비가 1.26:1, 패널 #FFF8EC와는 1.45:1. 색 말고 다른 단서도 없다. WCAG 1.4.11은 상태 표시에 3:1이나 색 외의 단서를 요구한다.

### 레퍼런스

- WCAG 2.2 1.4.11: https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast
- Material 3 탭 인디케이터(Flutter 커밋): https://chromium.googlesource.com/external/github.com/flutter/flutter/+/0bcd228e678d835ab8e8c7d0ca7e233e7d2af107%5E%21 — Primary 3dp, Secondary 2dp.
- Josh W. Comeau, 3D Button: https://www.joshwcomeau.com/animation/3d-button/ — 평소 −4px, hover −6px(250ms), 누름 −2px(34ms).

### 적용 사양 (권장 A)

- **A. 카테고리 색 채움 + 흰 글자 + 들림**: 선택 탭 면은 카테고리 색(제어 #2F7FD3, 명령 #8A5CE6, 값 #D9650B, 논리 #2F9A57), 흰 Jalnan2 22–24(4.12/4.42/3.61/3.57:1), 아래 립 4px edge 색(#205B99/#6141C2/#9C4908/#226F3F), Ink 3px 외곽선, +3px 들림, 1.06배 스프링 0.18초. 미선택은 Paper 면 + Ink 3px 외곽선, Muted 글자(4.03:1), 왼쪽에 카테고리 색 점 10px.
- **B. Ink 반전**(배속처럼 카테고리 없는 토글): 선택 면 Ink #262A3E + Sunny 글자(8.96:1), 미선택 Paper + Ink 글자. 대비 11.64:1. 화면당 한 그룹만.
- **C. 폴더 탭 + 언더바**: 선택 탭이 패널과 같은 Paper로 6px 올라와 이어 붙고 라벨 아래 4px 바(Ink 13.41:1 또는 카테고리 색). 미선택은 PaperDeep #F1E7D3 + Muted.
- 공통 모션: 전환 120–180ms, hover +2px·밝기 1.08배, 누름 −2px 34ms.
- 역할 정리: Primary 베이지는 주 행동 버튼에만. 선택 표시는 카테고리 색이나 Ink(`UITheme` 주석도 고친다).

피할 것: 같은 색 계열의 명도만 바꾸기, Primary·Sunny를 Paper 위 선택 표시로, 굵기만 바꾸기, 코랄 선택 표시, 외곽선 없는 글로우만.
