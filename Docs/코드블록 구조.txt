코드 블록(명령어 블럭)을 통해서 코딩하는 기능을 구현할거야
참고게임 : entry
문법 : 파이썬3

코드블록 종류
제어블록 -> for, while, break,continue, if, elif, else 등 흐름제어 구문

for :
모양 : 제어블록_1.png
텍스트 : for i in range(n):
입력값 : n (값블럭)

while :
모양 : 제어블록_1.png
텍스트 : while <condition>:
입력값 : condition (조건블럭)

if :
모양 : 제어블록_2.png
텍스트 : if <condition>:
입력값 : condition (조건블럭)

elif :
모양 : 제어블록_3.png
텍스트 : elif <condition>:
입력값 : condition (조건블럭)
특이사항 : if, elif 블럭 아래에만 붙을 수 있다. if, elif 블럭이랑 붙을 시 if, elif 블럭과 함께 제어블록_4.png 모양으로 변한다. 변했을 때 위의 condition은 유지.
변했을 때 텍스트 : 
첫줄 => if <condition>:
둘째줄 => elif <condition>:

else :
모양 : 제어블록_3.png
텍스트 : else:
특이사항 : if, elif 블럭 아래에만 붙을 수 있다. if, elif 블럭이랑 붙을 시 if, elif 블럭과 함께 제어블록_4.png 모양으로 변한다. 변했을 때 위의 condition은 유지.
변했을 때 텍스트 : 
첫줄 => if <condition>:
둘째줄 => elif <condition>:
셋째줄 => else:

특이사항 : elif, else로 생기는 여러개의 ㄷ자 모양은 무한이다.

break :
모양 : 제어블록_5.png
텍스트 : break

반환메서드 블록 : 반환값을 가지며, 언어자체에 없는 개발자가 정의한 메서드 블록
ex) attack(), get_pos_x(), get_nearest_enemy()

모양 : 반환메서드블록_1.png
매개변수 : 값블록을 받는 구조
반환값 : return (값블록)
텍스트 : method(a, b)

get_pos_x() :
모양 : 반환메서드블록_1.png
텍스트 : get_pos_x()
매개변수 : 없음
반환값 : 현재 x위치 (값블록)

get_pos_y() :
모양 : 반환메서드블록_1.png
텍스트 : get_pos_y()
매개변수 : 없음
반환값 : 현재 y위치 (값블록)

get_nearest_enemy() :
모양 : 반환메서드블록_1.png
텍스트 : get_nearest_enemy()
매개변수 : 없음
반환값 : 가장 가까운 enemy객체 (값블록)

보이드블록(void블록) : 반환값이 없으며, 언어자체에 없는 개발자가 정의한 메서드 블록

attack(enemy) :
모양 : 보이드블록_1.png
텍스트 : attack(enemy)
매개변수 : Enemy클래스 객체
반환값 : void

wait(float) :
모양 : 보이드블록_1.png
텍스트 : wait(n)
매개변수 : float -> 초를 의미
반환값 : void
의미 : float초만큼 멈춘다

값블록 : 자체로서 값, 인스터스를 나타낸다

모양 : 값블록_1.png
의미 : 정수,실수입력 부분이다. 플레이어가 직접 입력하므로 값을 결정한다
기본값 : 0, 0f

모양 : 값블록_2.png
의미 : 변수. 변수명 옆에 드롭다운버튼이 존재. 버튼을 눌러 변수에서 .연산자로 호출할 수 있는 메서드를 보여준다
텍스트 : 만약 enemy변수라면 enemy라고 표시

모양 : 값블록_3.png
의미 : 변수.method()구조. 반환값을 지닌다

enemy.get_distance(x, y) :
매개변수 :
x => 비교할 대상의 x좌표
y => 비교할 대상의 y좌표
x, y 둘다 값블록
반환값 : 실수 (값블록)

모양 : 값블록_4.png
의미 : 변수.method()구조.
반환값을 지니지 않는 형태. 현재 구현할 메서드는 존재하지 않는다

특이사항 : 변수의 드롭다운에서 반환값이 있는 메서드를 선택하면 값블록의 모양, 반환값이 없는 메서드를 선택하면 보이드메서드블록의 모양이 된다. 계속 드롭다운으로 변경 가능하다.

변수선언블록 :
모양 : 변수선언블록.png
텍스트 : (var) = (v)
var : 변수명으로서 플레이어가 입력한다. python의 네이밍 규칙을 따른다
v : 할당하는 값이다. 값블록이다.
특이사항 : 변수블록으로 변수가 선언되면 값블록인 변수블록이 생긴다. 선언이 해제되면 사라진다.

논리블록 :
모양 : 논리블록.png
True, False를  반환한다
종류 : ==, >, <, >=, <=, True, False
True, False말고는 좌우에 값블록이 들어간다

각각 맞는 모양이 존재한다 즉, 논리블록 부분에는 값블록이 안들어가며, 값블록부분에 논리블록이 들어가지 않는다
사진에서 세모만큼 밀린 부분이 있는데 이부분끼리 서로 결합한다.

UI:
코드  판넬
코드블록을 조합하여 코드를 만든다.
판넬 상단, 타이틀바에 def 메서드명이 존재. 메서드명 부분에 사용할 메서드명을 작성. 기본값은 f0 f1 f2 ...
Apply버튼 : def를 완성하고 apply버튼을 누르면 완성한 것으로 판단. 테스트용도로 콘솔에 현재 파싱된 파이썬 코드 string출력

Apply버튼을 누르면 판넬의 코드블럭을 읽고 파이썬 문법을 통해서 변환.
