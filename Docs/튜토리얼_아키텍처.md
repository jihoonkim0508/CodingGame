# 튜토리얼 구현 아키텍처 (Stage 1-1, 1-2)

대본: [flow_stage1/tutorial_1-1_1-2_대본.md](flow_stage1/tutorial_1-1_1-2_대본.md)

## 1. 방향

- **UI는 그대로 쓴다**: 대화창, 스포트라이트(어둡게·테두리·클릭 제한), 입력 브리지, 부팅/경고 오버레이.
- **진행 경로를 하나로 합친다**: Stage 1 전용 `StageOneTutorial`(섹션·줄 번호를 코드에 박아 둔 241줄)을 지우고, 범용 `TutorialDirector` + `TutorialSequence` asset으로 1-1·1-2를 만든다.
- 대사·발화자·대상·완료 조건은 asset(Inspector)에서 입력하고, 코드는 "신호가 오면 다음 단계"만 한다. 대사 수정에 코드 수정이 필요 없다.
- 옛 학습 규칙(`damage`/`range` 변수가 실제 스탯을 바꾸는 규칙, `Attack()` 표기 파서)과 옛 대사는 전부 지운다.

## 2. 결정된 규칙

| 항목 | 규칙 | 구현 |
|---|---|---|
| 대사 형식 | `발화자 : 대사`, 발화자는 대화창 하나마다 입력 | `TutorialText.speaker` 추가, 시퀀스 공용 `speakerName` 삭제 |
| 시스템 대사 | 발화자가 `시스템`이면 경고 UI | Director가 발화자로 판단(별도 단계 종류 불필요) |
| 거리 | 1 grid = 1, 맵 한 블록 = 2. 코드 `enemy.distance(get_my_pos())` | `Vector2` 클래스 추가(값 타입 `ValueType.Vector2`, Python 쪽 `Vector2(x, y)` 객체). `get_my_pos()` → `Vector2`, `enemy.distance(Vector2)` → float. 시뮬레이션 좌표 = 월드 XZ라 단위 변환 없음 |
| hp | `enemy.hp`는 프로퍼티(괄호 없음) | 이미 구현됨 |
| 웨이브 전환 | 로봇·코드 유지 | 이미 그렇게 동작(`ClaimRewards` → `ResetPrograms`는 실행 횟수만 초기화) |
| 스테이지 전환 | 로봇·코드 초기화 | 스테이지 맵 경로는 씬을 다시 불러와 초기화됨. 씬 안 `AdvanceStage`는 로봇을 유지함 → §6-7 |
| 웨이브 통과 | 기지가 살아 있으면 통과. 1-1·1-2는 지지 않는 것이 의도 | `Reward` 진입 = 통과. 실패 분기 없음 |
| 적 수 | 1-1·1-2 각 2마리 | **반영함**: `StageOneCampaign.asset` 3→2, 4→2 |
| 미리보기 | 실행 횟수 무제한, 공격 사거리 원 표시, 적이 모두 사라지면 1초 후 재시작 | **반영함**: 실행 한도 무제한, 미리보기 로봇 사거리 원(`effectRing`을 실행 시 복제해 씬 수정 없음). 1초 재시작은 원래 있던 동작 |
| 1-2 코드 삭제 | 힌트 안내 대사(C05) 직전에 교육 로봇 코드 삭제 | 해당 단계의 `clearProgram` |
| 회수 | 1-1·1-2 동안 잠금 | **반영함**: `DefenseSimulation.RecallUnlocked`(Stage 1 웨이브 3부터), 회수 버튼 비활성, 검사 추가 |
| 함수 실행 횟수 | 로봇 함수는 웨이브마다 5번(`for i in range(5): f()`), 반복문 해금 후 1번. 모든 스테이지 동일. 공격 횟수 한도 없음 | **반영함**: `FunctionRepeatLimit => PlayerFlow && LoopsUnlocked ? 1 : 5`. 공격 횟수 한도(`AttackLimitPerRobot`, `attackCountFactor`, 개발 옵션 `attackLimit`, `AttackLimitReached`) 삭제. 검사 추가 |
| 게임 시작 | 타이틀부터 시작 | 이미 구현됨. 씬 안 스테이지 진행 경로는 플레이 중 쓰이지 않음 |
| 옛 대사 | 전부 삭제 | §3 삭제 목록 |

## 5. 프로그램 일치 판정

교육 로봇의 `Program.Source`에서 첫 줄(`def …:`)을 빼고 들여쓰기·앞뒤 공백을 지운 뒤 `expectedCode`와 문자열 비교. 블록 → Python 변환기가 문법·타입을 이미 검증하므로 별도 파서는 두지 않는다.
교육 로봇 = 이 스테이지에서 처음 배치한 전사(1-1에서 전사가 2대 지급되므로 기준이 필요).
