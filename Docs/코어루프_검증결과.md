# 코어 루프 검증 결과

검증일: 2026-09-22 · 구현 v0.11 · Unity 6000.3.21f1

## 판정

스테이지 1의 5웨이브 코어 루프가 구현되어 있다. 초기 인벤토리에서 로봇 배치, 로봇 선택 후 코드 작성과 자동 적용, 전투 시작, 처치별 랜덤 블록 드랍, 웨이브 종료 후 수령, 코드 재작성과 다음 전투, 마지막 보상 수령 후 승리까지 연결된다.

## 실제 씬 실행 검증

Unity MCP Play Mode에서 `Defense.unity`의 실제 로봇·적·웨이브 정의와 초기 재고를 사용했다. v0.11의 35초 제한에서도 아래 결과를 다시 확인했다. 테스트용 능력치 변경이나 아이템 지급 없이 사수형 3대, 전사형 2대, 탱커형 1대를 배치했다. 전투 시간을 고정 틱으로 전진시켜 검증했으며 수동 마우스 플레이 테스트는 아니다.

| 로봇 | XZ 좌표 | 코드 |
|---|---|---|
| 사수형 1 | -8, 6 | `Attack()` |
| 사수형 2 | -4, 1 | `Attack()` |
| 사수형 3 | -8, -1 | `Attack()` |
| 전사형 1 | -10, 2 | `slash()` |
| 전사형 2 | -8, 2 | `slash()` |
| 탱커형 | -6, 2 | `block()` |

v0.10에서는 매 웨이브 코드 편집과 사용자 HUD의 전투 시작·보상 수령 버튼 이벤트를 호출했다. v0.11 재검증에서는 초기 배치 때 패널로 코드를 적용하고, 매 웨이브 HUD 시작 버튼과 동일한 보상 수령 메서드를 호출했다. 웨이브 간 편집 회귀 검증은 아래 별도 시나리오로 확인했다.

| 웨이브 | 처치 | 미수령 블록 | 잔여 적 | 수령한 블록 | 수령 후 상태 |
|---|---:|---:|---:|---:|---|
| 1 | 5 | 5 | 0 | 5 | 준비 |
| 2 | 8 | 8 | 0 | 8 | 준비 |
| 3 | 9 | 9 | 0 | 9 | 준비 |
| 4 | 10 | 10 | 0 | 10 | 준비 |
| 5 | 20 | 20 | 0 | 20 | 승리 |

모든 웨이브에서 수령 전 인벤토리 수량은 증가하지 않았고, 수령 시 미수령 블록 수만큼 증가했다. 수령 후 미수령 목록은 비었다. 최종 합계는 처치 52, 수령 블록 52, 돌파 0, 코어 체력 12다. 이 결과는 특정 배치에서의 기능 검증이며 최종 난이도 확정을 뜻하지 않는다.

## 추가 규칙 검증

`rtk proxy dotnet run --project Tests/Defense/Defense.Check.csproj`

- 전투 55개 + 코드/호환 45개 + 캠페인 81개 = 181개 통과.
- 빈 로봇 무행동, 아이템 수량 검사·예약·반환, 전투 중 편집 잠금, 중복 수령 거부, 마지막 보상 후 승리.
- 순수 시뮬레이션 테스트는 20초 설정에서 일시정지·조기 전멸·잔여 적 이월을 검증한다. 실제 씬은 35초이며 별도 Play Mode 검증에서 시간 만료 후 잔여 2마리, 다음 웨이브 10마리를 확인했다.
- 폭탄의 지연 착탄·비유도 고정 위치·이동 속도에 따른 회피·광역 1회 피해·비전문 피해 10%·시간 종료 때 투사체 취소.
- 사수형·전사형은 빠른 적에게도 실행 순간 사거리 안이면 즉시 확정 피해.
- 전장과 코드 미리보기에서 투사체 외형 생성, 발사 시 체력 유지, 착탄 시 체력 감소를 확인했다. 미리보기는 실제 전장 자원·체력·드랍을 변경하지 않는다.
- Unity 컴파일 성공, Inspector 투사체 참조 연결, Console 오류 0건.

## 현재 범위

v0.11 UI 회귀 검증: 실제 F 키 상태 입력으로 2x 전환, Tab 인벤토리 열기, 회수 버튼으로 로봇·블록 반환을 확인했다. 1웨이브 뒤 선언+while 묶음의 포인터 드래그 위치 `(160,-152)` 유지와 자동 적용, 중간 블록 우클릭 삭제 후 연결 유지·재고 1개 반환을 확인했다. 해당 재현에는 while 시험용 1개를 추가 지급했다. 종료 후 표시 중인 전투 LineRenderer는 0개였고, 돌파로 기지 HP가 10/12가 되면 체력바는 0.8333이었다. 적·로봇 hover 설명과 미리보기 로봇 1대·실제 전장 실행 0회도 확인했다.

현재는 스테이지 1과 5웨이브를 반복 시험하는 프로토타입이다. 다중 스테이지 콘텐츠, 세션을 넘는 저장/불러오기, 최종 아트·음향·밸런스는 후속 작업이다. 적은 기존 임시 프리팹을 일반병·속도병·탱커병으로 사용한다.
