# 튜토리얼 대본 (1-1 ~ 1-5, 2-1 ~ 2-2)

2026-11-04 학습 순서 개편: **반복 → 변수 → 조건**. 1-1 반복(전사 `slash()`), 1-3 변수(원거리 `attack(enemy)`), 2-1 조건(가까울 때만 사격).
이전 순서(1-1 변수 → 1-3 조건)의 대사는 git 기록(`develop` 159c7a9)에 있다. 1-1 A01~B05의 도입·배치 대사는 기존 것을 유지하고(A06만 수정), 나머지는 새 순서에 맞춘 **초안**이다. 기획 확인 전이며 바뀐 내용은 [임시변경점.md](../임시변경점.md) §25에 적었다.
`▶` 메모 중 원본에도 없고 승인되지도 않은 결정은 적지 않고, 사용자 결정 번호(Pn)만 가리킨다. 기획 답과 결정 목록은 [튜토리얼_명세서.md](../튜토리얼_명세서.md) §9.

| 원본 | 정리본 | 이유 |
|---|---|---|
| `get_nearst_enemy()` | `get_nearest_enemy()` | 실제 함수 이름(오타) |
| `enemyDistance` | `enemy_distance` | Python 변수 이름 규칙(snake_case) |
| `My_attack_range` | `my_attack_range()` | Python 이름 규칙(소문자 snake_case). 함수 블록으로 구현(사용자 결정 P10) |
| `slash(enemy)` | `slash()` | 2026-11-04: 변수를 뒤로 미뤄 대상 없이 사거리 안 360도를 베는 공격으로 변경 |

## 읽는 법

- `발화자 : 대사` 형식. 왼쪽이 발화자이며, 구현에서는 **대화창 하나(대사 한 줄)마다 발화자를 입력**한다(고정 이름 없음).
- 발화자가 `시스템`인 줄은 대화창이 아니라 UI(배너)로 표시한다.
- `▶` 줄: 구현 메모(진행 신호, 판정 조건). 기획 문장이 아니다.
- 단계 구성(행동·완료 신호·집중·화살표)은 `Assets/!_Project/Editor/Defense/TutorialSequenceBuilder.cs`에 있다. 편집기 안 위치 `1>2`는 "1번 줄 안쪽의 2번째 줄"이다.

## 구현 공통 규칙 (결정됨)

| 항목 | 규칙 |
|---|---|
| 학습 순서 | 1-1 반복 소개 → 1-2 반복 자유 플레이 → 1-3 변수 소개 → 1-4 변수 자유 플레이 → 1-5 반복·변수 보스 → 2-1 조건 소개 → 2-2 조건 자유 플레이 |
| 함수 실행 횟수 | 로봇 함수는 웨이브마다 **1번** 실행된다(모든 스테이지 동일). 여러 번 공격하려면 반복문을 쓴다. 공격 횟수 한도는 없음 |
| 반복문 | 스테이지 1·2의 반복은 `while True:`(멈추지 않고 웨이브 끝까지 반복)이다. 사거리 안에 적이 없으면 공격은 헛돌고 다음 바퀴에서 다시 시도한다. `for i in range(n)`은 스테이지 3에서 배운다 |
| 배치 자리 | 1-1·1-3·2-1의 배치 단계와 자유 플레이(1-2·1-4·2-2)의 새 로봇 배치는 길 옆 한 자리(Battle.Spot)만 허용한다. 자리는 이미 놓인 로봇보다 먼저 적을 만나는 빈 지점(0.4 간격으로 찾음) 중 거리 3 안에 길이 가장 많이 들어오는 곳이고, 누르면 그 자리에 정확히 놓인다. 길은 1.5칸 폭이라 칸 가운데가 아니라 옆 칸의 바깥쪽(길 중심에서 약 1.7)이 가장 가까운 자리다 |
| 실행 시작 | 사거리 안에 적이 들어와야 로봇 함수 실행이 시작된다 |
| 전사 `slash()` | 대상 없이 사거리 안 360도의 모든 적에게 같은 피해. 로봇이 한 바퀴 돌며 벤다 |
| 원거리 `attack(enemy)` | 저장한 적 한 명에게 피해. 샷건처럼 거리에 반비례(`사거리 / max(1, 거리)` 배율) — 가까울수록 세다 |
| 거리 단위 | 1 grid = 거리 1. 맵의 한 블록(타일) = 거리 2 |
| 거리 코드 | `enemy.distance(get_my_pos())`. `get_my_pos()`는 `Vector2` 객체를 돌려준다 |
| 웨이브 전환 | 로봇·코드 유지. 스테이지 전환 때만 초기화 |
| 웨이브 통과 | 기지(코어)가 살아 있으면 통과 |
| 프로그램 시작 | 코드 영역 왼쪽 위 시작 위치에 붙은 블록부터 실행한다(P7) |
| 미리보기 | 실전과 같이 함수 1회 실행, 공격 사거리 원 표시. 적이 모두 사라지면(로봇이 더 이상 때릴 수 있는 적이 없을 때 포함) 1초 후 다시 시작 |
| 회수 | 1-1·1-2 동안 잠금(1-3부터 가능) |
| 게임 시작 | 타이틀 화면부터 시작 |

```text
[1-3.B04] 안내자 : ‘개발’을 눌러 원거리 로봇의 명령을 만들자.

[반복 안에서 적 찾기]
[1-3.C01] 안내자 : 먼저 지난번에 배운 <b>while True</b> 블록을 시작 자리에 놓아 줘.\n원거리 로봇도 계속 쏘려면 반복이 필요해.

[1-3.D04] 안내자 : 위아래 이름이 같지?\n위에서 저장한 적을, 아래에서 공격할 대상으로 쓰는 거야.
[1-3.D05] 안내자 : 코드는 자동으로 적용돼.\n왼쪽에서 로봇이 <b>가장 가까운 적을 쏘는 모습</b>을 확인해 봐!

[1-3.D07] 시스템 : 오류 코드 접근 중! 코어 방어 준비!

[실전과 복습]
[1-3.E01] 안내자 : <b>‘전투 시작’</b>을 눌러 봐.\n원거리 로봇이 enemy로 정한 적을 쏘는지 지켜보자!
[1-3.E02] 안내자 : 전투가 시작됐어!\n원거리 로봇은 enemy에 저장한 적 <b>한 명</b>을 골라서 쏴.
▶ FirstAttack에 표시
[1-3.E03] 안내자 : 이번 웨이브를 마쳤어!\n<b>변수</b>에 적을 저장하고, 그 이름으로 공격 대상을 알려줬어.
[1-3.E04] 안내자 : 오늘 만든 명령은 이거야.\n<b>반복할 때마다: 적 찾기 → enemy에 저장 → attack(enemy)</b>
[1-3.E05] 안내자 : 이번 보상은 <b>원거리 공격 블록 하나</b>야!
[1-3.E06] 안내자 : <b>‘보상 수령’</b>을 눌러 다음 웨이브로 가자!
```

## 2-1 — 조건 소개: 가까이 왔을 때만 쏘기

```text

[2-1.A02] 안내자 : 원거리 공격에는 비밀이 하나 있어.\n<b>샷건</b>처럼 <b>가까이서 쏠수록</b> 피해가 커져!

▶ 완료: RobotPlaced. 표시된 자리(Battle.Spot)는 길이 거리 3 안에 가장 많이 들어오는 곳이라 조건이 참이 될 수 있다
[2-1.B03] 안내자 : 좋아! 방금 놓은 원거리 로봇을 눌러 봐.

[2-1.C02] 안내자 : 둘째 줄은 <b>적과 로봇 사이의 거리</b>를 재서 enemy_distance에 저장해.\n이름이 길지만, 지금은 ‘적까지의 거리’라고 읽으면 돼!
```
