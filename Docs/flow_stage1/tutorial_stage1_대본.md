# Stage 1 튜토리얼 대본 (1-1 ~ 1-4)

원본: `튜토리얼_대사목록_수정본(4w 수정본).txt`(기획, 2026-10-15 수령). 1-1~1-3은 이전본(`1s 3w~4w추가본`)과 같고 1-4가 새로 바뀌었다.
2026-10-25 최신 구성: 1-1 변수·조작 소개, 1-2 변수 자유 플레이, 1-3 조건문 소개. 1-1 A01~B02는 기존 대사를 유지하고, 이후 1-1 및 1-2·1-3은 초보자용 개정안을 사용한다.
1-4 조건문 자유 플레이와 1-5 변수·조건문 활용은 후속 구현 범위다. 아래 1-4 대사·연출은 기존 버전을 보존한 것으로, 새 구성의 구현 완료를 뜻하지 않는다.
개정 전 문서는 `[ID] ` 접두어와 `▶` 줄을 지우고 아래 표를 거꾸로 적용해 원본과 비교했다(2026-10-15 확인). 현재 1-1~1-3은 아래 초보자용 개정안을 기준으로 한다.
예외: 기획 확인 전 임시로 바꾼 대사는 [임시변경점.md](../임시변경점.md)에 전후를 적는다(이 경우 위 원본 비교는 그 변경만큼 다르다).
`▶` 메모 중 원본에도 없고 승인되지도 않은 결정은 적지 않고, 사용자 결정 번호(Pn)만 가리킨다. 기획 답과 결정 목록은 [튜토리얼_명세서.md](../튜토리얼_명세서.md) §9.

## 읽는 법

- `발화자 : 대사` 형식. 왼쪽이 발화자이며, 구현에서는 **대화창 하나(대사 한 줄)마다 발화자를 입력**한다(고정 이름 없음).
- 발화자가 `시스템`인 줄은 대화창이 아니라 UI(배너)로 표시한다.
- `집중`·`상호작용`·`추가 효과`·`코드`는 대사가 아니라 연출·진행 메모다.
- `▶` 줄: 구현 메모(진행 신호, 판정 조건). 기획 문장이 아니다.

## 구현 공통 규칙 (결정됨)

| 항목 | 규칙 |
|---|---|
| 거리 단위 | 1 grid = 거리 1. 맵의 한 블록(타일) = 거리 2 |
| 거리 코드 | `enemy.distance(get_my_pos())`. `get_my_pos()`는 `Vector2` 객체를 돌려준다. 기존 `get_distance(x, y)`는 이 `Vector2` 방식으로 대체 |
| 웨이브 전환 | 로봇·코드 유지. 스테이지 전환 때만 초기화. 한 스테이지 안에서는 맵 동일 |
| 웨이브 통과 | 기지(코어)가 살아 있으면 통과. 1-1~1-4는 지지 않는 것이 의도 |
| 적 수 | 1-1~1-3 각 오류 코드 2마리(5회 실행으로 처치 가능: 1마리당 베기 2번 × 2 = 4번). 1-4는 "더 많은 오류 코드"(1-4 E02)라 2마리보다 많게, 로봇 2대 × 5회로 다 막을 수 있게 맞춘다(시뮬레이션 후 데이터 수정). 코어 피해는 적 1마리당 1(원본 "체력이 1 닳도록") |
| 실행 시작 | 사거리 안에 적이 들어와야 로봇 함수 실행(5회)이 시작된다(기획 확인) |
| 프로그램 시작 | 코드 영역 왼쪽 위 시작 위치에 붙은 블록부터 실행한다. 다른 곳에 떨어져 있는 블록은 실행되지 않는다(P7) |
| '코드 :' 표기 | 플레이어가 블록으로 직접 만드는 부분(기획 확인). 1-4 B02처럼 "그대로 남아 있네"로 보여 주기만 하는 곳은 예외 |
| 미리보기 | 실행 횟수 무제한, 공격 사거리 원 표시. 적이 모두 사라지면(로봇이 더 이상 때릴 수 있는 적이 없을 때 포함) 1초 후 다시 시작 |
| 회수 | 1-1·1-2 동안 잠금(1-3부터 가능) |
| 함수 실행 횟수 | 로봇 함수 `f`는 웨이브마다 `for i in range(5): f()`처럼 5번 실행. 반복문 해금 후에는 1번만 실행(그래서 반복문을 쓰게 됨). 모든 스테이지 동일. 공격 횟수 한도는 없음 |
| 게임 시작 | 타이틀 화면부터 시작 |
| 옛 대사 | 1-1~1-5 JSON·MD 전부 삭제 |

```text
CodingGame 튜토리얼 대사 목록 (수정본)

작성 기준
- 플레이어는 코드를 직접 타이핑하지 않고 블록 편집기에서 로봇의 프로그램을 수정한다.
- 아래의 '코드 :' 줄은 블록 편집기의 Python 미리보기와 학습 내용을 보여주는 참고 표기다.

- 조건식의 숫자는 로봇의 스탯이 아니라 행동 실행 여부를 판정하는 기준값이다.
-시스템 으로 시작하는건 모두 UI로 표시할것
-1s - 1w 에서 체력이 1 닳도록 할것
```
