# Stage 1 튜토리얼 대본 (1-1, 1-2)

기획 원본(수정본)을 그대로 옮겼다. 각 대사 앞의 `[ID]`와 `▶` 줄만 구현용으로 덧붙인 것이다.
`[ID] ` 접두어와 `▶` 줄을 지우면 원본과 같다(2026-10-13 줄 단위 비교로 확인, 줄 끝 공백만 차이).
**승인된 수정 1건**: 1-2 B05의 `.distance` → `.distance(get_my_pos())`(매개변수는 대사 작성 이후 추가된 사양이라 반영).

## 읽는 법

- `발화자 : 대사` 형식. 왼쪽이 발화자이며, 구현에서는 **대화창 하나(대사 한 줄)마다 발화자를 입력**한다(고정 이름 없음).
- 발화자가 `시스템`인 줄은 대화창이 아니라 경고 UI(배너 + 경고음)로 표시한다.
- `집중`·`상호작용`·`추가 효과`·`코드`는 대사가 아니라 연출·진행 메모다.
- `▶` 줄: 구현 메모(진행 신호, 판정 조건). 기획 문장이 아니다.

## 구현 공통 규칙 (결정됨)

| 항목 | 규칙 |
|---|---|
| 거리 단위 | 1 grid = 거리 1. 맵의 한 블록(타일) = 거리 2 |
| 거리 코드 | `enemy.distance(get_my_pos())`. `get_my_pos()`는 `Vector2` 객체를 돌려준다. `enemy.hp`는 프로퍼티(괄호 없음) |
| 웨이브 전환 | 로봇·코드 유지. 스테이지 전환 때만 초기화. 한 스테이지 안에서는 맵 동일 |
| 웨이브 통과 | 기지(코어)가 살아 있으면 통과. 1-1·1-2는 지지 않는 것이 의도 |
| 적 수 | 1-1·1-2 각 2마리(5회 실행으로 처치 가능: 1마리당 베기 2번 × 2 = 4번) |
| 미리보기 | 실행 횟수 무제한, 공격 사거리 원 표시. 적이 모두 사라지면 1초 후 다시 시작 |
| 회수 | 1-1·1-2 동안 잠금(1-3부터 가능) |
| 함수 실행 횟수 | 로봇 함수 `f`는 웨이브마다 `for i in range(5): f()`처럼 5번 실행. 반복문 해금 후에는 1번만 실행(그래서 반복문을 쓰게 됨). 모든 스테이지 동일. 공격 횟수 한도는 없음 |
| 게임 시작 | 타이틀 화면부터 시작 |
| 옛 대사 | 1-1~1-5 JSON·MD 전부 삭제 |
