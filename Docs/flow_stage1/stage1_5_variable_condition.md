## 4. 조건 결과 확인

**연출**  
[`attackDistance = 10`. 적의 거리가 14일 때 `14 <= 10`, `False`; 거리가 8일 때 `8 <= 10`, `True`와 공격을 보여준다.]

**코드 예시 — 보스와 거리 14**

```python
attackDistance = 10
enemyDistance = 14
14 <= 10
# False
```

**코드 예시 — 보스와 거리 8**

```python
attackDistance = 10
enemyDistance = 8
8 <= 10
# True
```

**안내자**  
아직 공격하지 않아.

**안내자**

## 5. 변수 값만 바꿔 행동 조절

**연출**  
[`attackDistance`를 10에서 15로 바꾸고 공격 범위가 넓어지는 것을 보여준다. 조건문 코드는 그대로 둔다.]

**코드 예시 — 변경 전**

```python
attackDistance = 10
```

**코드 예시 — 변경 후**

```python
attackDistance = 15
```

**코드 예시 — 변경한 전체 코드**

```python
attackDistance = 15

if enemyDistance <= attackDistance:
    Attack()
```

**안내자**  
이번에는 조건문은 그대로 두고 변수 값만 바꿔보자.

**안내자**  
조건문은 바뀌지 않았어.

**안내자**  
하지만 변수 값이 바뀌어서 공격을 시작하는 거리도 바뀌었지.

**안내자**  
변수를 쓰면 필요한 값을 한 곳에서 관리할 수 있어.

**안내자**  
변수 값만 바꿔도 그 변수를 사용하는 코드의 행동을 바꿀 수 있어.

### 플레이어 상호작용

- **목표:** 공격 시작 거리를 변수로 조절한다.
- **행동:** 조건문은 그대로 두고 `attackDistance`의 값만 변경한다.
- **입력 예시:**

```python
attackDistance = 15

if enemyDistance <= attackDistance:
    Attack()
```
- **성공 피드백:** 공격 시작 거리가 달라진다.
- **힌트:** `if`의 비교 구조는 그대로 두고 변수 선언의 숫자만 바꿔봐.

### 플레이어 상호작용

- **힌트:** 보스가 지나가면 `attackDistance` 값을 확인하고 조절해.
