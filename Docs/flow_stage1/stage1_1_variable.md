## 3. 변수와 값 만나기

**연출**  
[코드 화면에 `damage = 10` 표시. `damage`, `=`, `10`을 차례로 강조한다. 이름표가 붙은 상자에 10이 들어가는 그림을 보여준다.]

**코드 예시 — 처음 저장된 공격력**

```python
damage = 10
```

**안내자**  
로봇이 공격하려면 공격력이 얼마나 되는지도 알아야겠지?

**안내자**  
`damage`는 로봇의 공격력을 저장하는 변수야.

**안내자**  
변수는 값을 보관하는 이름이 붙은 상자라고 생각하면 돼.

**안내자**  
지금은 `damage`라는 상자에 `10`이 들어 있어.

**안내자**  
왼쪽의 `damage`는 변수의 이름이야.

**안내자**  
오른쪽의 `10`은 변수에 저장되는 값이고.

**안내자**  
가운데 `=`는 오른쪽 값을 왼쪽 변수에 저장한다는 뜻이야.

**안내자**  
이 코드는 “`damage`라는 변수에 `10`을 저장한다”는 뜻이야.

**안내자**  
현재 `damage` 값이 10이기 때문에 로봇이 10의 피해를 줬어.

### 플레이어 상호작용

- **목표:** 변수의 이름과 값을 확인한다.
- **행동:** `damage`가 변수 이름이고 `10`이 저장된 값임을 확인한다.
- **입력 예시:**

```python
damage = 10
```
- **성공 피드백:** 코드를 읽고 실제 공격 결과와 연결한다.

## 4. 변수 값 바꿔보기

**연출**  
[코드 편집 화면에서 10을 강조한다. 입력 후 상자 값이 10에서 20으로 바뀐다. 새 적이 사거리 안에 들어오고 로봇이 공격한다.]

**코드 예시 — 공격력을 20으로 변경**

```python
damage = 20
```

**안내자**  
변수의 값은 계속 똑같아야 하는 건 아니야.

**안내자**  
현재 값은 10. 이번에는 직접 20으로 바꿔보자.

**안내자**  
좋아! `damage`의 값이 20으로 바뀌었어.

**안내자**  
이번에는 20의 피해를 줬어.

**안내자**  
로봇 자체는 그대로인데 변수에 저장된 값이 바뀌었기 때문이야.

**안내자**  
변수는 값을 저장하고 필요하면 그 값을 바꿀 수 있어.

### 플레이어 상호작용

- **목표:** `damage` 값을 바꾼다.
- **행동:** 저장 값을 10에서 20으로 변경한다.
- **입력 예시:**

```python
damage = 20
```
- **성공 피드백:** 로봇 공격에 20 DAMAGE가 표시된다.
- **힌트:** 변수 이름은 그대로 두고 오른쪽 값을 20으로 바꿔봐.
