# 통합 개발 에디터

Unity 메뉴 **CodingGame > 개발 에디터**에서 연다. 현재 활성 씬의 유일한 `DefenseBattle`과 그 전투에 연결된 캠페인 asset을 자동으로 읽는다. 전투가 없거나 여러 개이면 설정 오류로 표시한다. 창을 여는 것만으로 씬이나 asset을 수정하지 않는다.

## 편집과 적용

- **Edit Mode**: 밸런스, 캠페인, 보급, 튜토리얼을 원본 asset의 SerializedProperty로 편집한다. Unity Undo/Redo를 지원한다. `원본 저장`은 설정 검사를 통과한 asset을 저장한다.
- **Play Mode**: 캠페인과 로봇·적 정의의 복사본을 편집한다. `적용`을 누르면 실행 중 수치가 즉시 변경된다. 기지·로봇·적 체력은 최대치로 초기화하고 기존 투사체를 제거한다. 위치·시간·코드·인벤토리·보상 수령 상태는 유지한다. 현재 웨이브의 스폰 수량·간격·지연도 변경되며 이미 생성된 적은 제거하지 않는다. 현재 스폰 항목 추가·삭제·경로 변경은 재시작이 필요하다. 밸런스 탭의 `현재 세션 적용값`에서 실행 중인 규칙과 로봇 수치를 확인한다.
- `수치 적용 확정`은 런타임 적용 후 원본 캠페인·로봇·적 asset까지 저장한다. Play 종료 후에도 유지된다. 확정하지 않은 변경은 종료 후 `Play 변경값 비교`에서 검토·확정하거나 폐기한다.
- Unity 상단의 일반 Play는 개발 에디터를 비활성화한 정상 실행이다. 개발 에디터의 `Play 시작 (개발툴 포함)`은 선택한 세션 조건과 테스트 옵션을 적용하고 개발 UI를 연다.
- 캠페인이 없는 기존 씬은 `캠페인 > 현재 씬 콘텐츠 이관`으로 asset을 만들고 연결한다. 25웨이브의 성장 수치·스폰 항목과 보급·보상을 비교한다. 연결한 씬은 Unity의 씬 저장으로 저장한다. 기존 직렬화 값은 이전 씬 이관을 위해 보존하며, 연결된 캠페인이 실행 수치의 원본이다.

## 테스트 의미

`단독 웨이브 초기화`는 새 세션이다. 이전 적과 사용 자원을 가져오지 않는다. `이전스테이지까지의 보상`은 선택한 스테이지보다 이전 스테이지의 준비 로봇·블록과 종료 보상을 합산한다. 현재 스테이지의 지난 웨이브는 합산하지 않는다. 현재 웨이브 준비 보급은 정상 지급한다. 과거 처치 코인과 사용량은 재현하지 않는다.

`시나리오`에는 stage-wave, 이전 스테이지 보상 정책, 재고, 코인, 로봇 배치·레벨·체력·코드, 옵션, 제한시간을 저장한다. 코드 트리는 기존 Newtonsoft JSON 의존성을 사용한 문자열로 보관하여 Unity의 중첩 직렬화 깊이 제한을 피한다. 실제 편집은 Game View의 기존 개발 툴에서 한다.

`캠페인 1~5 실행`은 고정 틱으로 정상 보급·보상·진행 API를 호출한다. 기존 검사에서 사용하던 경로 범위 기반 자동 배치를 사용한다. 기지 파괴, 시간 초과, 시작 조건 누락은 실패/선행 조건 미충족으로 기록한다. 자동 배치 결과는 최적 전략이나 실제 클릭·드래그 UI 검증을 의미하지 않는다.

순수 로직 검사는 `dotnet`이 필요하며 별도 프로세스로 실행한다. 전투 검사는 연결된 씬의 Play Mode가 필요하다. 검사는 동시에 하나만 실행한다.

스폰 OFF는 스폰 시계를 멈춘다. 인벤토리 제한 OFF는 수량 부족만 우회하며 해금을 유지한다. 전체 해금과 무제한 수량은 별도다. 계산 옵션은 다음 틱, 표시 옵션은 즉시 적용된다. 과거 보급·보상을 다시 지급하지 않는다.

로그는 이벤트 소비 전에 관찰하며 본게임과 미리보기를 구분한다. 최근 1,000개 로그와 ID별 실제 피해·처치·누수 집계를 보관한다. `결과 JSON 저장`은 `TestResults/Editor/`에 실행 설정 snapshot, 옵션, 결과, 이벤트, 체력·시간·지표를 저장한다. Play 종료 전 보고서도 창에 보존한다.

## 구현 확인

전투 55개, 프로그램 70개, 캠페인 148개, 25웨이브 학습 흐름, 블록 컴파일 검사 및 Editor 옵션 검사가 통과했다. Unity에서 8개 탭 생성과 컴파일을 확인했다. 목표 가림 검사는 현재 배치의 투영 영역 9점을 검사하므로 다른 배치·해상도에서도 별도로 실행한다.
