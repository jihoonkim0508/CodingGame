# 1-2 여러 변수 — 여러 값을 사용해보자

**스테이지 ID:** 1-2

## 학습 목표

- 여러 변수를 사용해 서로 다른 값을 저장한다.
- `damage`와 `range`가 각각 공격력과 사거리를 나타냄을 이해한다.
- 변수 값을 바꾸면 로봇의 능력과 게임 결과가 달라짐을 확인한다.
- 적의 경로와 사거리를 고려해 로봇을 배치한다.

## 2. 두 개의 변수

**연출**  
[이름표가 다른 상자 두 개를 표시한다. `damage`에는 20, `range`에는 5를 넣는다.]

**코드 예시 — 공격력과 사거리**

```python

```

**안내자**

**안내자**  
`damage`에는 공격력이 들어있고,

**안내자**  
`range`에는 공격할 수 있는 거리가 들어있어.

**안내자**  
변수마다 이름을 다르게 만들면 서로 다른 값을 따로 저장할 수 있어.

**안내자**  
그래서 어떤 값이 필요한지 쉽게 구분할 수 있지.

## 3. 사거리 값의 변화

**연출**  
[사거리 5를 원으로 표시한다. 적이 거리 6에서 접근해 사거리 안에 들어온다. `range = 8`로 바꾸자 공격 범위가 넓어진다.]

**코드 예시 — 변경 전 사거리**

```python
range = 5
```

**코드 예시 — 사거리 확장**

```python
range = 8
```

**안내자**  
지금 공격 범위는 5야.

**안내자**  
적이 아직 공격 범위 밖에 있어.

**안내자**  
이제 범위 안으로 들어왔어.

**안내자**  
`range` 값을 바꾸면 어떻게 될까?

**안내자**  
공격할 수 있는 범위가 더 넓어졌어.

**안내자**  
변수에 어떤 값을 넣느냐에 따라 게임 속 결과도 달라질 수 있어.

### 플레이어 상호작용

- **목표:** 사거리 값을 바꿔본다.
- **행동:** `range`를 5에서 8로 바꾸고 범위 변화를 확인한다.
- **입력 예시:**

```python
range = 8
```
- **성공 피드백:** 공격 사거리 표시가 넓어진다.
- **힌트:** `range`는 사거리 변수야. 오른쪽 숫자를 바꿔봐.
