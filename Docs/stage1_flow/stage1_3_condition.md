# 1-3 조건 — 조건문으로 판단하기

- 조건문이 상황을 확인한 뒤 행동하게 하는 코드임을 이해한다.

- 조건이 참일 때만 들여쓴 행동 코드가 실행됨을 이해한다.

## 2. 조건문과 if

**연출**  
[`if`와 비교식, `Attack()`을 차례로 강조한다.]

**코드 예시 — 적이 가까울 때 공격**

```python
if enemyDistance <= 10:
    Attack()
```

**안내자**  
이럴 때 사용하는 게 조건문이야.

**안내자**  
`if`는 “만약 ~라면”이라는 뜻이야.

**안내자**  
`enemyDistance`는 현재 적과 로봇 사이의 거리야.

**안내자**  
`<=`는 왼쪽 값이 오른쪽 값보다 작거나 같은지 확인해.

**안내자**  
이 코드는 “만약 적과의 거리가 10 이하라면 공격한다”는 뜻이야.

## 3. 조건이 참인지 거짓인지

**연출**  
[적의 거리가 15일 때 `15 <= 10`, `False`를 표시하고 로봇은 대기한다. 거리가 9가 되면 `9 <= 10`, `True`를 표시하고 공격한다.]

**코드 예시 — 거리 15일 때**

```python
enemyDistance = 15
15 <= 10
# False
```

**코드 예시 — 거리 9일 때**

```python
enemyDistance = 9
9 <= 10
# True
```

**안내자**  
지금 적과의 거리는 15. 15는 10 이하가 아니니까 조건을 만족하지 않아.

**안내자**  
`True`는 조건을 만족함, `False`는 조건을 만족하지 않음이야.

**안내자**  
`if`는 조건이 `True`일 때 안쪽 코드를 실행해.

**안내자**  
이번에는 거리가 9야. 9는 10 이하니까 조건을 만족했어.

**안내자**  
조건을 만족했어. 공격 시작!

## 4. 조건문 직접 만들기

**연출**  
[`if`, `enemyDistance`, `<=`, `10`, `Attack()` 코드 조각을 보여주고 조립 UI를 연다.]

**코드 예시 — 플레이어가 완성할 코드**

```python
if enemyDistance <= 10:
    Attack()
```

**안내자**  
이번에는 직접 만들어보자.

**안내자**  
적과의 거리가 10 이하일 때 공격하도록 만들어봐.

**안내자**  
좋아! 이제 실제로 작동하는지 확인해보자.

### 플레이어 상호작용

- **목표:** 코드 조각을 올바른 순서로 조립한다.
- **행동:** 거리가 10 이하일 때 `Attack()`을 실행하는 조건문을 완성한다.
- **입력 예시:**

```python
if enemyDistance <= 10:
    Attack()
```
- **성공 피드백:** 완성된 조건문으로 웨이브를 시작한다.
- **힌트:** `if` 다음에는 조건을 놓고, 참일 때 실행할 행동은 들여써.

## 5. 조건문으로 웨이브 진행

**연출**  
[웨이브 시작. 먼 적에게는 공격하지 않고, 거리가 10 이하가 되면 공격한다. 클리어 후 기본 형태를 요약한다.]

**코드 예시 — 조건문 기본 형태**

```python

    행동
```

**안내자**  
조건을 만족했어. 공격 시작!

**안내자**  
이제 로봇에게 언제 행동해야 하는지 알려줄 수 있어.

**안내자**  
조건이 맞으면 행동한다. 이것이 조건문의 기본이야.

### 플레이어 상호작용

- **목표:** 조건문이 실제로 작동하는지 확인한다.
- **행동:** 적의 거리에 따라 로봇이 대기하거나 공격하는 것을 관찰한다.
- **성공 피드백:** 조건이 참이 되는 시점에 공격이 실행된다.
- **힌트:** 적의 거리와 `enemyDistance <= 10`의 결과를 비교해봐.
