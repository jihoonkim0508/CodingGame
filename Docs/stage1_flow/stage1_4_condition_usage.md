# 1-4 조건 — 조건을 바꿔보자

**스테이지 ID:** 1-4

## 학습 목표

- 비교 기준값에 따라 로봇의 행동 시점이 달라짐을 이해한다.
- 적의 속도와 상황을 보고 적절한 조건값을 선택한다.
- 조건값이 너무 작을 때 전투 결과가 어떻게 달라지는지 확인한다.
- 조건값을 수정해 전략을 개선한다.

## 2. 기준값 5와 10 비교

**연출**  
[`enemyDistance <= 5`일 때 사거리 5를 표시한 후, 기준을 10으로 바꾸고 범위를 더 넓게 표시한다.]

**코드 예시 — 가까이 왔을 때 공격**

```python
if enemyDistance <= 5:
    Attack()
```

**코드 예시 — 더 멀리서부터 공격**

```python
if enemyDistance <= 10:
    Attack()
```

**안내자**  
먼저 이렇게 설정해보자.

**안내자**  
이 경우 적이 아주 가까이 와야 공격을 시작해.

**안내자**  
값을 10으로 바꾸면 적이 더 멀리 있을 때부터 공격할 수 있어.

**안내자**  
같은 `if`를 사용해도 조건값에 따라 행동이 달라져.

**안내자**  
거리 5는 가까운 적만 공격하고 시작이 늦어.

**안내자**  
거리 10은 더 먼 적도 공격하고 시작이 빨라.

## 3. 상황에 맞는 조건값 선택

**연출**  
[빠르게 이동하는 적과 로봇의 위치를 보여준다. 입력값을 `?`로 표시해 플레이어가 기준을 고르게 한다.]

**코드 예시 — 플레이어가 기준값을 정하는 코드**

```python
if enemyDistance <= ?:
    Attack()
```

**안내자**  
이번 웨이브에서는 적이 빠르게 이동할 거야.

**안내자**  
공격을 언제 시작하는 게 좋을지 생각해봐.

**안내자**  
조건의 값에 따라서 로봇의 행동이 달라진다는 걸 기억해.

### 플레이어 상호작용

- **목표:** 공격을 시작할 기준 거리를 정한다.
- **행동:** 적의 이동 속도와 로봇 위치를 보고 조건값을 입력한다.
- **입력 예시:**

```python
예: if enemyDistance <= 8:
    Attack()
```
- **성공 피드백:** 선택한 기준에 따라 공격 시작 시점이 달라진다.
- **힌트:** 빠른 적을 놓친다면 기준값을 더 크게 해 일찍 공격을 시작해봐.

---

## 4. 실패를 보고 조건 수정하기

**연출**  
[기준값 2를 적용해 공격 기회가 짧아지고 적을 놓치는 장면을 보여준다. 기준을 8로 바꾸고 공격이 빨라지는 모습을 보여준다.]

**코드 예시 — 공격이 늦게 시작되는 예**

```python
if enemyDistance <= 2:
    Attack()
```

**코드 예시 — 수정한 기준값 예**

```python
if enemyDistance <= 8:
    Attack()
```

**안내자**  
공격을 너무 늦게 시작해서 적을 놓치고 있어.

**안내자**  
조건의 값을 바꿔보는 것도 방법이야.

**안내자**  
좋아. 이제 공격을 더 일찍 시작할 수 있어.

### 플레이어 상호작용

- **목표:** 전투 결과를 보고 조건을 수정한다.
- **행동:** 적을 놓치면 기준값을 더 큰 값으로 바꿔본다.
- **입력 예시:**

```python
if enemyDistance <= 8:
    Attack()
```
- **성공 피드백:** 공격을 더 일찍 시작할 수 있다.
- **힌트:** 공격이 늦다면 `enemyDistance`와 비교하는 기준값을 확인해.

### 플레이어 상호작용

- **성공 피드백:** 조건에 맞춰 적을 막으면 1-4를 클리어한다.
- **힌트:** 전투 결과를 보며 기준값을 조절해.
