## 입력과 진행 규칙

- 대사의 성공 문장은 해당 입력이나 전투 결과를 확인한 뒤 표시한다.
- 공백과 `20.0` 같은 동등한 숫자 표기를 허용한다.
- 자유 선택 과제는 예시 문자열과 문자 단위로 비교하지 않는다.
- 숫자는 0 초과 100 이하로 제한한다. 선언 누락, 들여쓰기 오류, 조건 밖 공격은 거부한다.
- 수치 검증 실패 시 이전 코드와 수치를 보존한다.
- 공격 대기 시간 중 적이 조건 거리 밖으로 이동하면 조건을 다시 확인해 이전 판단으로 공격하지 않는다.
- 변수만 사용하는 초기 두 웨이브는 기존 공격 명령으로 자동 공격한다.
- Stage 1 학습 중에는 반복 실행 횟수 제한으로 조건 확인이 조기에 종료되지 않도록 한다.
- Stage 2 진입 시 Stage 1 전용 피해·실행 규칙을 종료한다.
- 전투 전에는 기존 블록 편집기로 추가 로봇과 코드를 준비할 수 있다. 누출 후 재시작은 로봇과 학습 진행을 함께 초기화한다.

기존 회귀 테스트 중 구형 `Attack()` 출력 기대값은 실제 `attack(enemy)`로 수정했다. 기본 `enemy`가 자동 제공되는 현재 컴파일러에 맞춰 미선언 변수 검사를 별도 `target` 변수로 유지했다. 보상 전용 검사에서는 무작위 반복 블록 해금이 공격 실행 규칙을 바꾸지 않도록 검사 조건을 분리했다.

Play Mode 검증 후 유휴 Editor에서는 Unity AI Toolkit의 계정 API 네트워크 시간 초과 경고가 관찰됐다. Stage 1 컴파일·실행 오류는 없으며, 위 성공·실패 흐름 검사는 통과했다.
