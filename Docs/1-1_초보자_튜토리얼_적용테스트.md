## 적용 내용

- 설치 완료 전 A01~B02 대사는 기존 문장 유지.
- 이후 코딩 설명을 42단계 시퀀스로 적용. 핵심은 ‘적 찾기 → enemy에 기억하기 → 기억한 적 공격하기’.
- 빈칸 선택, 블록 추가, 이름 입력을 별도 행동으로 나누고 실제 조립 상태로 완료 판정.
- enemy 저장 이름과 공격 대상 이름을 각각 강조. 두 줄의 위→아래 실행 순서를 설명.
- 코드 완성 후에 미리보기 공격을 시작하고 실제 명중을 확인한 뒤 진행.
- 입력 완료 시 입력칸 선택을 해제해 다음 설명 중 남은 키 입력이 코드를 바꾸지 않도록 처리.
- 혼동을 주던 드래그 시연을 1-1에서 제거하고 화살표로 조작 위치 안내.
- Unity 메뉴 `Tools > Develop > Apply Beginner Tutorial 1-1`로 1-1 asset만 갱신 가능.

## 플레이 중 발견해 수정한 어색함

1. 변수 이름 입력칸 화살표가 윗줄과 겹침: 이름 입력칸도 아래에서 가리키도록 변경하고 재플레이 확인.
2. 여러 적이 통과하거나 안내를 읽는 중 전투가 끝나면 ‘한 마리’, ‘계속 지켜보자’가 맞지 않음: ‘적이 코어에 도착해서 체력이 줄었네. 그래도 코어가 살아 있으면 다음 웨이브로 갈 수 있어!’로 수정.
3. 인벤토리 variable 글자 부분은 이름 입력으로 반응할 수 있음: D03에 주황색 테두리를 누르도록 명시. 실제 테두리 클릭으로 블록 삽입은 두 플레이에서 확인.

마지막 2·3번 문구 변경은 전체 플레이 뒤 Unity 적용 메뉴로 다시 저장하고 asset 반영을 확인했다. 변경 후 전체 플레이를 한 번 더 반복하지는 않았다. 단계·판정 로직은 두 번째 전체 플레이에서 확인한 그대로다.
