# Stage 1 튜토리얼 구현·교차검증

2026-10-23. 기준은 [Stage 1 대본](flow_stage1/tutorial_stage1_대본.md)의 1-1~1-5다. Stage 1 대사는 이 문서 한 곳에서 읽고, Stage 2 대사는 기존 후속 문서에서 읽는다.

## 1-1에서 이어받은 진행 방식

`TutorialSequenceBuilder.OneOne()`은 대사 ID마다 `TutorialStep`을 만들고 `TutorialDirector`가 재생한다. 시스템 발화는 경고 배너, 설명은 대화창, 클릭·배치·코드 조립은 행동 단계로 나눈다. 대화창은 타이핑·이전/다음 이동을 지원하며 클릭 대상과 겹치면 위로 이동한다.

`TutorialInputBridge`가 현재 대상만 입력을 허용하고, `TutorialPointer`와 `TutorialSpotlight`가 화살표·집중·반투명 블록 드래그 시연을 표시한다. 행동은 클릭 신호, `ProgramMatches`, `SlotFilled`, `PreviewHit` 등의 실제 결과로 완료한다. 설명을 넘기는 것만으로 행동이 완료되지 않는다. 전투 중 대사는 게임을 계속 진행하고 첫 공격·누출·웨이브 종료 신호를 기다린다.

1-1의 대사·단계·승인된 생략(E04)과 기존 연출은 유지했다. 새 데이터 필드의 기본값만 함께 직렬화된다.

## 웨이브별 연결

| 구간 | 진행과 판정 |
|---|---|
| 1-2 | 도입 → 로봇·개발 버튼 두 단계 → 점(.)·거리·체력 설명 → 기존 코드 비우기 → 힌트로 직접 조립 → 정답 뒤 닫기 → 전투 시작 → 실제 종료 대사 |
| 1-3 | 거리 변수 추가 위치와 값 칸·위치 인자 칸을 차례로 안내 → 분리된 비교식 조립 판정 → 오른쪽에 사거리·실제 거리 비교 True/False 표시 → if 안에 slash 연결 판정 → 편집기 닫기·전투 → 첫 공격·종료 대사 |
| 1-4 | 두 번째 전사 배치 → 첫 번째 전사의 기존 코드 확인 → 사거리 변수 삽입 → 비교식의 사거리를 변수로 교체 → 두 번째 전사의 편집기로 이동 → 혼자 조립·힌트 → 전투·종료 |
| 1-5 | 두 전사의 기존 변수·조건 코드 유지·점검 → 힌트 → 플레이어가 전투 시작 → 일반 적 처리 직후 보스 연속 소환 → 약 1초 집중 후 자동 카메라 복귀 → 실제 보스 공격 대사 → 보스 처치·코어 생존 시 성공 대사 |
| 1-5 실패 | 진행 중 대사·보스 집중 중단 → G01~G04 → `1S-5W 다시 시작` / `바탕화면으로 나가기` → 재도전 시 H01과 준비·점검으로 복귀 |

1-3/1-4의 변수 삽입 화살표는 원래 있던 slash/if의 인자 칸을 잘못 가리키지 않는다. 편집기는 연결된 명령 사이에도 블록을 삽입하며 기존 뒤쪽 연결을 보존한다. 새 변수 선언 블록이 연결된 다음 해당 값 칸을 가리킨다. 거리 함수가 선택되면 `get_my_pos()`를 넣을 위치로 이동한다.

자유 작성 구간은 블록 팔레트·코드 영역·힌트를 허용하고 정답 전 닫기/ESC를 막는다. 60초 동안 미완성이면 힌트 화살표를 표시한다. 정답은 코드 내용과 블록의 중첩을 검사한다. 이미 완성된 1-5 코드는 지우지 않으며 두 로봇을 점검하는 시간을 둔다.

## 보스전과 재도전 상태

`SpawnEntry.waitForClear`를 설정한 보스 그룹은 앞 그룹의 생성과 전장 정리가 끝날 때까지 대기한다. 마지막 일반 적을 베기로 처치한 틱에도 보스를 즉시 생성한다. 별도 준비 단계나 시작 버튼은 없다. 보스 집중 연출과 E 구간은 전투를 일시정지하지 않는다.

전사 두 대가 각자 함수를 5번 실행하는 기존 규칙에 맞춰 1-5를 일반 적 2마리·보스 1마리로 구성했다. 전용 `TutorialBoss`의 기본 체력은 30이며 기존 Tank/웨이브 배율이 적용된다. 보스가 코어에 도달하면 코어가 파괴되도록 돌파 피해를 코어 최대 체력으로 설정했다. 보스가 남은 채 제한시간이 끝나도 클리어 대사 대신 실패로 진행한다. 반복문이나 추가 자동 실행을 도입하지 않았다.

재도전은 해당 시도의 전투 시작 전 코어·코인·누적 기록·적 진행도와 로봇 배치·코드를 복원한다. 전투 중 적·투사체·베기 예약·보스 신호·연출은 제거하고 함수를 다시 실행할 수 있게 만든다. 보급과 보상을 중복 지급하지 않는다. 1-1부터 재시작하지 않는다.
