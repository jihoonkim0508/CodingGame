## 대본 차이의 적용 기준

원본 대사는 `tutorial_stage2_대본.md` §3에 보존했다. 실제 빌더에는 §7-Q1/Q2의 현 전투 규칙 기준 교정안을 적용했다. 사거리 스탯 변경 실습은 추가하지 않았다.

‘바탕화면으로 나가기’는 기존 타이틀의 종료 함수 `GameFlow.QuitGame()`에 연결했다. 빌드에서는 앱 종료, 에디터에서는 Play 종료다. 별도 Desktop 씬은 만들지 않았다.

2-1 for 초기값은 기존 팔레트의 10을 유지하고 플레이어가 3으로 바꾼다. 원거리 수업의 for·적 찾기 골격은 제공하지만 공격과 대상은 직접 연결한다. 자유 실습에서는 골격을 자동 입력하지 않는다.

전투 초기 조정값: 같은 Stage 2 맵의 경로 0, 웨이브 제한 120초. 일반 웨이브는 기본 오류 코드 2/3/3/3마리(체력 오버라이드 12, 속도 0.8, 누출 피해 1), 마지막은 보스 1마리(체력 오버라이드 110, 속도 0.55, 누출 피해 12). 실제 수치에는 기존 스테이지 스케일링이 적용된다. 최종 난이도 확정값은 아니다.
