# 튜토리얼 후속 대본 — Stage 2

2026-10-23 작성. 기준 원본은 [최신 Stage 1 대본](../flow_stage1/tutorial_stage1_대본.md)이다. 기존 인계서의 과거 상태보다 이 대본과 현재 구현을 우선한다. 1-5는 첨부 원문을 반영한 [Stage 1 대본의 1-5](../flow_stage1/tutorial_stage1_대본.md#1-5)로 대체했다. 이 문서의 2-1~2-5는 기존 대본의 규칙과 교육 방식을 이어 작성한 신규 구현 대본이다. Stage 2의 학습 순서는 게임_기획.md의 의도(조건 → 반복 → 반복+조건)를 따른다.
전사형과 기존 거리 API를 계속 사용한다. 새 로봇 직업·분기는 이 범위에 도입하지 않는다.

## 연출·진행 규칙

- 1-4 종료 상태: 전사 2대, 각각 적·거리·사거리 변수 3줄과 if 안의 slash. 1-5에서 그대로 점검한다.

- 로봇 선택 → 개발 버튼은 같은 대사로 두 단계, 각각 화살표 표시.
- 2-2 B04: for 블록을 시작 위치로 옮기는 시연, 반복 안쪽 연결 지점 화살표. 적 찾기와 공격을 모두 안쪽에 연결해야 완료.
- C01/C03 실습: 블록 팔레트·코드·힌트 허용, 정답 전 닫기/ESC 잠금, 60초 힌트 화살표. 정답 뒤 D01에서 닫기 허용.
- 2-2~2-5 C04: 완성된 반복 안쪽을 비추며 실행 순서를 정리한다.
- 2-5: 첫 번째 로봇 점검 후 두 번째 로봇 편집기로 전환하여 혼자 작성(1-4 방식).
