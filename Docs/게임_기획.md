# 게임 기획

## 개요

| 항목 | 내용 |
|---|---|
| 장르 | 3D 로우폴리 쿼터뷰 타워 디펜스 + 블록 코딩 |
| 학습 언어 | Python 3 문법을 블록으로 조립(직접 타이핑 없음. Stage 1 학습 입력창만 예외) |
| 대상 | 코딩을 처음 접하는 대학생, 초보~기초 수준 |
| 플랫폼 | PC, 마우스·키보드, 16:9 |
| 세계관 | 개발툴(코어)에 침입하는 오류 코드를 로봇으로 막는다 |
| 참고 | 경로·사거리 표현은 킹덤러쉬, 카메라 구도는 명일방주 |

핵심은 **작성한 코드와 전투 결과의 인과관계를 읽을 수 있는 것**이다. 문법 오류는 적용 전에 막고, 문법은 맞지만 비효율적인 코드는 실행해서 결과로 보여준다.

## 코어 루프

1. **배치**: 정비 단계에서 로봇을 허용 영역에 자유 배치한다(격자 없음). 경로 위에는 탱커만 설치한다.
2. **코딩**: 배치한 로봇을 클릭 → `개발`로 코드 편집기를 연다. 블록을 조립하면 자동 적용되고 미리보기에서 바로 실행된다.
3. **전투**: 시작하면 각 로봇이 자기 코드를 실행한다. 코드가 없는 로봇은 아무것도 하지 않는다.
4. **보상**: 웨이브가 끝나면 그 웨이브에 정해진 보상 블록을 수령하고 다음 정비로 넘어간다.

- 웨이브는 적 전멸 또는 제한시간 종료로 끝난다. 남은 적과 미등장 적은 다음 웨이브로 이월(보상 없음).
- 코어 체력 12. 적이 코어에 닿을 때마다 1 감소, 0이면 패배.
- 스테이지 5웨이브를 마치면 다음 스테이지로 진행한다.

스테이지 3 자유 플레이

### 현재 구현(`DefenseCurriculum.cs`, `StageOneCampaign.asset`)

2026-11-04 개편: 학습 순서를 **반복 → 변수 → 조건**으로 바꿨다. 위 기획자 원문(변수 → 조건 → 반복)과 다르다. 지급표 원본은 `DefenseCurriculum.cs`이고, 튜토리얼 빌더가 같은 표를 `StageOneCampaign.asset`에 쓴다.

| 단계 | 주제 | 준비 보급 | 종료 보상 |
|---|---|---|---|
| 1-1 | 반복: while True로 계속 베기 | 전사형, slash, while | slash |
| 1-2 | 반복 자유 플레이 | 전사형, while | while |
| 1-3 | 변수: 적을 저장해 원거리 공격 | 원거리, `variable =`, `get_nearest_enemy()`, variable, attack | attack |
| 1-4 | 변수 자유 플레이 | 원거리, `variable =`, `get_nearest_enemy()`, variable, while | slash |
| 1-5 | 반복과 변수: 보스 종합 실습 | `variable =`, `get_nearest_enemy()`, variable, while | attack |
| 2-1 | 조건: 가까운 적만 쏘기 | 원거리, if, 비교, `variable =`, variable ×2, `get_my_pos()`, 숫자 | 비교 |
| 2-2 | 조건 자유 플레이: 거리 기준값 조정 | if, `get_my_pos()`, variable, 숫자 | 비교 |
| 2-3 | 거리 조건과 감속 | 유틸형, slow, if, `variable =` ×2, variable ×3, `get_nearest_enemy()`, `get_my_pos()`, while, 숫자 | slow |
| 2-4 | if / elif / else | 버프형, elif, else, buff, True, False | 비교 |
| 2-5 | 거리 조건과 분기 종합 | — | if |
| 3-1~3-5 | for 반복, 횟수 변경, while·break·continue | 폭탄형·탱커형, for ×2, 숫자 ×3, boom, block / 3-4: while·break·continue | for 등 |

보급은 해당 웨이브 준비 때 한 번, 보상은 웨이브 종료 후 한 번 지급한다. 블록은 소모되지 않고 코드에 "예약"되며, 로봇 회수 시 반환된다. 자유 플레이 웨이브는 새 로봇이 앞 단계에서 배운 코드를 써야 전투를 시작한다(1-2: 새 전사에 for·slash, 1-4: 새 원거리에 적 찾기·변수·attack, 2-2: 원거리 두 대 모두 거리 if 안의 attack).

### 의도와 차이(결정 필요)

- 기획자 원문은 1스테이지 변수·조건, 2스테이지 반복이다. 구현은 1-1 반복, 1-3 변수, 2-1 조건(2026-11-04 사용자 요청). 스테이지 1·2의 반복은 `while True:`이다(2026-11-05).
- 2-3 이후와 3스테이지의 주제·지급은 이전 구성을 유지했다(3스테이지 주제가 for를 다시 다룸).

## 로봇

| 로봇 | 고유 명령 | 사거리 | 피해 | 주기(초) | 특징 |
|---|---|---|---|---|---|
| 원거리 | `attack(enemy)` | 5.5 | 22 | 1.2 | 저장한 적 한 명에게 피해. 샷건처럼 가까울수록 강함(아래 규칙) |
| 전사형 | `slash()` | 3.2 | 14 | 0.8 | 대상 없이 사거리 안 360도 모든 적에게 같은 피해. 로봇이 한 바퀴 돌며 벤다 |
| 폭탄형 | `boom(enemy)` | 4.8 | 8 | 1.6 | 비유도 투사체, 착탄 범위 피해. 빠른 적은 피할 수 있음 |
| 유틸형 | `slow(enemy)` | 4.3 | 3 | 1.1 | 감속 |
| 버프형 | `buff()` | 5 | 0 | 2 | 주변 로봇 공격력·사거리·속도 강화. 최대 1대 |
| 탱커형 | `block(enemy)` | 2.3 | 2 | 3 | 유일하게 체력(140)이 있음. 경로 위에 설치, 몸으로 저지 + 범위 스턴 |

- 다른 직군 명령은 10% 효율로 동작한다. 예외: 폭탄형·원거리의 `block()`, 탱커의 `buff()`는 배치는 되지만 동작하지 않는다("호환되지 않는 명령").
- 동시 설치 6대. 레벨 최대 2, 레벨업 비용 50코인, 레벨당 ×1.2. 시작 코인 100, 처치당 5. 회수 시 강화 비용 환급.

## 적

| 적 | 유형 | 체력 | 속도 | 비고 |
|---|---|---|---|---|
| 일반병 | Normal | 55 | 1.65 | Stage 2~5 |
| 속도병 | Fast | 55 | 1.65 | 유형 배율로 체력 ×0.75, 속도 ×1.3 |
| 탱커병 | Tank | 55 | 1.65 | 유형 배율로 체력 ×1.5, 속도 ×0.75 |
| 오류 코드 | Normal | 20 | 1.4 | Stage 1 전용 |
| 빠른 오류 코드 | Fast | 22 | 2.6 | Stage 1 전용(1-4) |
| 보스 오류 코드 | Tank | 160 | 0.8 | Stage 1 전용(1-5) |

적 체력·속도는 진행도 p = (스테이지-1)×5 + 웨이브 순번으로 증가한다: 체력 ×(1 + 0.045p + 0.0015p²), 속도 ×(1 + 0.025p + 0.0005p², 원래의 1.7배 상한), 웨이브별 배율 `0.9, 1, 1.05, 1.15, 1`.

## 블록

| 분류 | 블록 |
|---|---|
| 행동 | `attack(enemy)`, `slash()`, `boom(enemy)`, `slow(enemy)`, `block(enemy)`, `buff()`, `wait(n)` |
| 제어 | `if`, `elif`, `else`, `for i in range(n)`, `while`, `break`, `continue` |
| 값·정보 | 숫자, `variable =`(선언), `variable`(참조), `get_nearest_enemy()`, `get_pos_x()`, `get_pos_y()`, `enemy.get_distance(x, y)`, `enemy.hp`(읽기 전용), `True`, `False` |
| 비교 | `==`, `<`, `>`, `<=`, `>=` |

- 값 슬롯과 논리 슬롯은 모양이 달라 서로 끼워지지 않는다(`ReferencesImg/` 블록 이미지 참고).
- `elif`·`else`는 `if`/`elif` 바로 뒤에만 붙는다.
- 미리 정의된 변수는 없다. `enemy`도 `enemy = get_nearest_enemy()`처럼 선언해야 쓸 수 있고, 공격 블록의 대상 칸이 비면 컴파일 오류다. 저장한 적이 사라지면 거리는 무한대, `hp`는 0.
- 적을 대상으로 하는 함수는 사거리 안에 적이 들어와야 한 번의 실행을 시작한다(빈 실행이 반복 한도를 쓰지 않도록).
- 레벨업은 1-2부터 열린다. 1-1에서는 버튼이 회색으로 비활성화된다.
- 공격 로봇을 지급할 때 대상 지정용 `get_nearest_enemy()`·variable 블록을 로봇 수만큼 함께 지급한다.

## 디자이너용 밸런스 규칙

- **함수 실행**: 로봇 함수는 웨이브마다 1번만 실행된다(모든 스테이지 동일). 계속 공격하려면 반복문을 직접 쓴다. 1-1에서 반복을 먼저 배운다.
- **반복 횟수**: `for i in range(n)`의 한 바퀴에서 공격이 맞힐 적이 없거나 조건이 거짓이라 아무 행동도 못 했으면, 그 바퀴는 횟수를 쓰지 않고 0.25초 뒤 다시 한다. 그래서 `range(n)`은 "공격 n번"이다. `continue`로 넘긴 바퀴는 횟수에 들어간다.
- 공격 횟수 제한은 없다. 미리보기도 함수를 1번만 실행하고, 때릴 적이 없어지면 1초 뒤 처음부터 다시 시작한다.
- 회수는 1-1·1-2 동안 잠기고 1-3부터 열린다.
- 제한시간: Stage 1은 120초, Stage 2~5는 35초.
- 원거리 `attack` 피해는 `사거리 / max(1, 거리)` 배율이 붙는다(가까울수록 강함, 1 이내에서 최대). 2-1 조건 수업이 이 점을 쓴다.
- 모든 수치는 `StageOneCampaign.asset`과 `Defense/Data/*.asset`에 있고 개발 에디터에서 조정한다.
