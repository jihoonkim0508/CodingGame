# 코딩 패널 3탭: 자연어 블록 · 파이썬 블록 · 파이썬 타이핑

코딩 작업 공간 머리줄(`def robot_1 ():` 오른쪽)에 탭 3개를 두고, 같은 코드를 세 가지 모습으로 바꿔 보여 준다.

| 탭 | 보이는 것 | 편집 방법 |
|:---:|:---:|:---:|
| 자연어 | 엔트리·스크래치처럼 한국어 문장 블록 | 끌어서 놓기 |
| 블록 | 지금의 파이썬 문법 블록 | 끌어서 놓기 |
| 파이썬 | 여러 줄 텍스트 입력창(VS Code Dark+ 색, 줄 번호) | 직접 타이핑 |

기본 탭은 **블록**(지금 화면)이다. 튜토리얼과 기존 검사는 그대로 돈다.

## 원칙: 커밋 하나 + 모드별 기록

- **커밋**: 로봇에 넘길 수 있는 마지막 코드 하나. 블록 트리(시작 위치 흐름)로 만들 수 있었던 가장 최근 상태다.
  - 블록 탭(자연어·블록)에서 고치면 트리는 언제나 만들어지므로 고칠 때마다 커밋된다. 빈칸, 타입 오류, 짝 없는 `elif` 같은 의미 오류도 그대로 커밋된다.
  - 파이썬 탭에서는 타이핑이 0.5초 멈출 때 텍스트를 읽어 보고, **문법 오류가 없을 때만** 커밋한다.
  - 커밋마다 번호가 1씩 오른다. 시작 흐름이 그대로인 편집(허공 블록만 옮김)은 커밋이 아니다.
- **모드별 기록**: 각 모드는 떠날 때 자기 화면을 그대로 기록해 둔다. 기록에는 떠날 때의 커밋 번호를 붙인다.
  - 블록 기록: 블록 배치 전체(허공 블록 묶음과 좌표 포함). 자연어와 블록은 글자만 다르고 배치가 같으므로 기록 하나를 같이 쓴다.
  - 파이썬 기록: 텍스트 전체(문법 오류 포함)와 커서 위치.
- **모드에 들어갈 때**
  - 기록의 커밋 번호가 지금 커밋 번호와 같으면(= 다른 모드에서 아무것도 고치지 않았으면) 기록을 그대로 되살린다. 오류 난 텍스트, 허공 블록이 떠날 때 모습 그대로 나온다.
  - 다르면(= 다른 모드에서 고쳤으면) 기록을 지우고 지금 커밋에서 새로 만든다. 이때 허공 블록과 문법 오류 텍스트는 사라진다.
- 그래서 **문법 오류는 다른 모드로 넘어가지 않는다.** 다른 모드는 언제나 커밋 기준으로 열린다. 파이썬 탭에서 오류가 있는 채로 블록 탭에 가면, 블록 탭은 마지막 커밋을 보여 주고 상태줄에 `파이썬 탭에 문법 오류가 있어 마지막 정상 코드로 열었어요 (N번째 줄: 이유)`를 띄운다. 파이썬 탭으로 돌아오면 오류 난 텍스트가 그대로 있다(그 사이 블록 탭에서 고치지 않았다면).

### 예

| 순서 | 한 일 | 결과 |
|:---:|:---:|:---:|
| 1 | 블록 탭에 허공 블록 2묶음을 둔 채 파이썬 탭으로 | 블록 기록 저장(커밋 5). 텍스트는 시작 흐름만 |
| 2 | 파이썬 탭에서 `whlie True:`를 쳐서 문법 오류 | 빨간 밑줄. 커밋은 5 그대로 |
| 3 | 블록 탭으로 | 커밋 번호 같음 → 허공 2묶음까지 그대로. 파이썬 기록(오류 텍스트) 저장 |
| 4 | 파이썬 탭으로 바로 복귀 | 오류 텍스트 그대로 |
| 5 | 오타를 고쳐 `while True:` | 커밋 6 |
| 6 | 블록 탭으로 | 블록 기록은 커밋 5라 지움 → 커밋 6에서 새로 만듦. 허공 블록은 사라짐 |

## 탭별 동작

### 자연어 ↔ 블록

- 블록 모양, 위치, 연결은 그대로 두고 **글자만** 바꾼다. 색과 크기는 글자 길이에 맞춰 다시 잰다. 팔레트 블록 글자도 같이 바뀐다.

### 파이썬 탭 모양

- VS Code Dark+: 바탕 #1E1E1E, 글자 #D4D4D4, 키워드(if·elif·else·while·for·in·break·continue·pass) #C586C0, True·False #569CD6, 함수 호출 #DCDCAA, 변수 #9CDCFE, 숫자 #B5CEA8, Enemy.Tank 등 #4EC9B0, 주석 #6A9955. 왼쪽에 줄 번호(#858585), 커서 줄은 옅은 띠, 커서는 흰색.
- 입력창 글자는 투명하게 두고 같은 자리에 색 글자(TMP 색 태그만)를 겹쳐 그려, 커서와 선택이 글자와 맞는다. 물결 밑줄은 그 위에 그린다.

### 커밋 → 파이썬 텍스트

- 시작 위치 흐름만 쓴다. 검사 없이 찍는 출력기(지금의 `ExpressionText` 방식)를 써서 의미 오류가 있어도 텍스트가 나온다.
- 빈칸은 `___`, 몸통이 빈 `if`/`while`은 `pass`로 쓴다.

### 파이썬 텍스트 → 커밋

- 읽을 수 있는 문법은 블록에 있는 것만이다: `if/elif/else`, `while True`, `for i in range(n)`, `break`, `continue`, 변수 대입, 블록 목록의 함수와 값, 비교, `+`. `___`는 빈칸, `pass`는 빈 몸통이 된다.
- 문법 오류(오타 `whlie`, 모르는 함수, 괄호·콜론 빠짐, 들여쓰기 깨짐)가 있으면 그 줄에 **빨간 물결 밑줄**을 긋고 상태줄에 `N번째 줄: 이유`를 띄운다. 커밋하지 않는다.

### 자동 완성 (IntelliSense)

- 목록과 매개변수 힌트는 VS Code 모양: 둥근 상자(#252526, 테두리 #454545), 고른 줄 #04395E, 글자 #D4D4D4, 자연어 글자 #9D9D9D.

- 글자를 2개 이상 치거나 Ctrl+Space를 누르면 커서 아래에 후보 목록을 띄운다.
  - 후보: 블록 목록의 함수(`get_nearest_enemy()`, `shoot(`, `wait(` …), 키워드(`if`, `while True:`, `for i in range(`), 지금 코드에서 대입한 변수 이름, 변수 뒤 `.` 다음에는 `.hp`, `.distance(`, `.is_dead()`, `.type`, `Enemy.` 다음에는 `Normal`, `Fast`, `Tank`.
  - 각 후보 옆에 자연어 글자를 작게 붙인다. 예: `get_nearest_enemy()  가장 가까운 적`
  - ↑↓로 고르고 Tab 또는 Enter로 넣는다. Esc로 닫는다.
- `(`를 치면 매개변수 힌트를 띄운다. 예: `wait(초)  〔초〕 초 기다리기`
- 이 스테이지 팔레트에 아직 안 열린 블록은 후보에 넣지 않는다.

### 오류와 에러

두 가지를 따로 보여 준다.

| 구분 | 뜻 | 예 | 표시 | 커밋·실행 |
|:---:|:---:|:---:|:---:|:---:|
| 오류 (문법) | 블록으로 못 만듦 | `whlie`, 모르는 함수, 콜론 빠짐, 들여쓰기 깨짐 | 빨간 물결 밑줄 (파이썬 탭) | 커밋 안 함 |
| 오류 (의미) | 블록은 되지만 컴파일 안 됨 | 빈칸 `___`, 타입 안 맞음, 짝 없는 `elif` | 빨간 테두리 블록 / 빨간 밑줄 | 커밋은 함, 로봇은 행동 안 함 |
| 에러 (사전 검사) | 실행은 되지만 제대로 안 먹힐 코드 | 원거리 로봇에 `slash()` | 노란 밑줄 / 노란 테두리 블록 + ⚠ | 커밋·실행 둘 다 함 |

- 에러는 이 로봇의 역할(`RobotRole`)을 보고 검사한다. 검사 기준은 이미 있는 `Rules.Compatibility`를 그대로 쓴다. 줄을 읽어 검사하므로 다른 줄에 오류가 있어도 에러는 따로 보인다.
- 블록 탭(자연어·블록)에서는 문제가 있는 **줄 블록**(흐름에 놓인 명령 블록) 머리에 굵은 테두리(4px)와 왼쪽 끝의 `!` 표시를 단다. 오류(그 줄이나 안에 끼운 값 블록의 의미 오류)는 빨강, 에러는 노랑이고, 한 줄에 둘 다 있으면 빨강이다. 테두리는 끌기와 칸 끼우기를 막지 않는다. 줄에 마우스를 올리면 메시지가 뜬다. 고칠 때마다, 탭을 바꿀 때마다 커밋에서 다시 계산한다.

| 검사 | 기준 | 메시지 |
|:---:|:---:|:---:|
| 효과 없음 | `Compatibility == Ineffective` (사수·폭격형의 `block`, 탱커의 `buff`) | 이 로봇은 ○○을(를) 해도 효과가 없어요 |
| 권한 없음 | `Compatibility == Undecided` (허락 없는 `block`, `buff`) | ○○은(는) 이 로봇에게 허락되지 않아 동작하지 않아요 |
| 약해짐 | `Compatibility == Reduced` (원거리 로봇의 `slash()` 등 다른 역할 기술) | ○○은(는) 이 로봇의 기술이 아니라 약하게 들어가요 |
| 오래된 적 | 반복 밖에서 정한 적 변수를 반복 안에서 계속 씀 (지금 상태줄 경고) | 반복 안에서 적을 다시 찾아 주세요 |

- 메시지는 줄(블록)에 마우스를 올리면 뜨고, 상태줄에는 `오류 N · 에러 M`과 첫 번째 메시지를 띄운다. 오류가 있으면 오류 메시지가 먼저다.
- 새 오류·에러가 생기면(어느 탭이든) 그 줄 옆에 메시지 풍선이 세 번 깜박이며 나타나 1.5초 머문 뒤 사라진다. 테두리·밑줄·`!`는 남는다. 같은 줄의 같은 문제는 다시 띄우지 않고(탭을 바꾸거나 다른 줄을 고쳐도), 로봇 코드를 처음 열 때도 띄우지 않는다. `!`(블록 탭은 줄 블록 왼쪽, 파이썬 탭은 줄 번호 옆)를 누르면 같은 방식으로 다시 보여 준다.
- 에러는 모드를 바꿔도 같은 블록·줄에 그대로 따라간다(커밋에서 다시 계산하므로).
- 자동 완성 목록에서도 이 로봇에게 에러가 날 함수는 회색 + ⚠로 보여 준다.

### 실행

- 로봇에는 **커밋**이 컴파일될 때만 적용한다. 컴파일이 안 되면 "미완성 · 로봇이 행동하지 않음 · 이유"를 띄운다.
- 블록 탭에서 허공 블록이 있으면 미완성으로 치는 지금 규칙은 그대로 둔다.

### 그 밖

- 파이썬 탭에서는 팔레트를 흐리게 하고 끌 수 없게 한다. 블록 도감, 비우기, 닫기는 세 탭 모두 쓸 수 있다.
- 되돌리기 기록은 커밋 단위로 쌓는다.
- 마지막으로 고른 탭은 패널을 닫았다 열어도 유지한다. 모드별 기록은 로봇마다 따로 둔다. 튜토리얼 중에는 블록 탭으로 연다.

## 자연어 블록 글자

`〔 〕`는 끼우는 칸이다. 엔트리 말투를 따랐다.

| 블록 | 지금 글자 | 자연어 글자 |
|:---:|:---:|:---:|
| If | `if 조건:` | 만약 〔조건〕 이라면 |
| Elif | `elif 조건:` | 아니고 만약 〔조건〕 이라면 |
| Else | `else:` | 아니면 |
| While | `while True:` | 계속 반복하기 |
| For | `for i in range(n):` | 〔n〕 번 반복하기 |
| Break | `break` | 반복 멈추기 |
| Continue | `continue` | 다음 반복으로 넘어가기 |
| DeclareVariable | `value = enemy` | 〔이름〕 을(를) 〔값〕 (으)로 정하기 |
| Variable | `variable` | 〔이름〕 |
| .distance(pos) | `.distance(pos)` | 와(과) 〔위치〕 사이 거리 |
| .hp | `.hp` | 의 체력 |
| .is_dead() | `.is_dead()` | 이(가) 쓰러졌는가? |
| .type | `.type` | 의 종류 |
| Wait | `wait(seconds)` | 〔초〕 초 기다리기 |
| Attack / Shot | `shoot(Enemy)` | 〔적〕 에게 쏘기 |
| Block | `block(` | 〔대상〕 막기 |
| Boom | `boom(` | 〔대상〕 에 폭탄 던지기 |
| Slow | `slow(` | 〔대상〕 느리게 하기 |
| Slash | `slash()` | 베기 |
| Buff | `buff()` | 강화하기 |
| NearestEnemy | `get_nearest_enemy()` | 가장 가까운 적 |
| PosX / PosY | `get_pos_x()` | 내 x 위치 / 내 y 위치 |
| MyPos | `get_my_pos()` | 내 위치 |
| AttackRange | `my_attack_range()` | 내 공격 범위 |
| Number / Float | `0` / `0f` | 〔0〕 |
| Arithmetic | `a + b` | 〔a〕 + 〔b〕 |
| EnemyTypeName | `Enemy.Normal` 등 | 일반 적 / 빠른 적 / 탱커 |
| Comparison | `a == b` | 〔a〕 〔=〕 〔b〕 (선택지: = ≠ < > ≤ ≥) |
| True / False | `True` / `False` | 참 / 거짓 |

`block`, `boom`, `slow`의 칸은 `shoot`처럼 적(`Enemy`) 하나라서 〔적〕으로 쓴다(`HasEnemyArgument`). `get_pos_x`, `get_pos_y`는 로봇 자신의 위치다(`DefenseProgram`의 `robot.Position`). 자연어 탭에서는 빈칸 안내도 한국어(적, 초, 조건, 위치)로 바뀌고, `enemy.`의 점은 그리지 않는다.

## 검사

- 모든 블록 종류를 넣은 프로그램이 블록 → 파이썬 → 블록, 블록 → 자연어 → 블록을 오가도 트리가 같다.
- 빈칸, 타입 오류, 짝 없는 elif가 든 프로그램이 파이썬 탭을 다녀와도 같은 오류 메시지를 낸다.
- 위 "예" 표의 1~6을 그대로 돌려 각 단계 결과가 표와 같다.
- 파이썬 탭에 문법 오류를 넣으면 그 줄에 빨간 밑줄이 생기고 로봇 코드는 바뀌지 않는다.
- `get_n`을 치면 `get_nearest_enemy()`가 후보 첫 줄에 뜨고 Tab으로 들어간다. `wait(`를 치면 매개변수 힌트가 뜬다.
- 사수 로봇에 `slash()`, 탱커에 `buff()`를 넣으면 노란 에러가 뜨고 로봇은 그대로 실행된다. 빈칸이 있으면 빨간 오류가 뜨고 로봇은 멈춘다.
- 파이썬 탭에서 정답 코드를 타이핑하면 로봇이 블록으로 짠 것과 똑같이 움직인다.
- 블록 탭에서 빈칸 줄은 빨간 테두리, 사수의 `slash()` 줄은 노란 테두리가 동시에 뜨고, 줄에 마우스를 올리면 메시지가 뜬다.
- 세 탭의 화면과 자동 완성, 빨간 밑줄, 노란 밑줄, 블록 테두리 화면을 찍어 `Report/`에 남긴다.
