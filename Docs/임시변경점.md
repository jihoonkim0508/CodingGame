## 1. 1-1 A04~A06: 경로·코어 체력 설명 대사 추가

**이유**: 원본은 A06의 `집중`에 "적이 들어오는 경로, 코어 체력 표시"가 있지만, 그것을 설명하는 대사가 없다. 화면이 경로와 체력을 비추는 동안 무엇인지 알려 주는 대사를 넣었다.

**변경 전**

| ID | 대사 | 집중 |
|---|---|---|
| A04 | 잠깐, 거기 있는 너! 나 좀 도와줄 수 있어?! | |
| A05 | 공격 로봇을 배치해서 오류 코드들을 막아야 해! | (구현) 적 경로 |
| A06 | 먼저 로봇을 배치하고, 적의 정보를 확인하는 방법부터 알아보자! | 경고 알림, 개발툴 화면, 적이 들어오는 경로, 코어 체력 표시 (구현: 코어 체력) |

**변경 후**

| ID | 대사 | 집중 |
|---|---|---|
| A04 | 잠깐, 거기 있는 너! 나 좀 도와줄 수 있어?! | |
| A04a (추가) | 봐, 오류 코드들은 이 길을 따라서 코어로 몰려와! | 적 경로 |
| A04b (추가) | 이건 코어 체력이야. 오류 코드가 코어에 닿을 때마다 줄어들어. | 코어 체력 표시 |
| A04c (추가) | 체력이 다 닳으면 개발툴이 멈춰버려. 그럼 우리도 끝이야! | 코어 체력 표시 |

- A05는 앞 대사와 이어지도록 "그러니까"만 붙였다.
- 용어는 "코어"로 썼다(A03 원본과 같음). 단, 화면의 체력바 글자는 아직 "기지 12 / 12"다.

**확인 요청**: 대사 문구, 용어(코어/기지) 통일 방향.

대사는 그대로이고 화면 연출만 바꿨다.

| ID | 변경 전 | 변경 후 |
|---|---|---|
| B02 "이제 맵에서 로봇을 놓을 위치를 정하자 …" | 적 경로를 밝힘 | 로봇을 놓을 수 있는 맵 영역을 박스로 표시(1-4 두 번째 로봇 배치도 같음) |

## 8. 맵 교체(map_v2)

- 스테이지 1 맵을 받은 `map_v2`로 바꿨다(`Stage01_v2.prefab`). 길이 더 길어졌다(37칸, 꺾임 8번).
- 적 경로와 코어 위치는 맵 에디터에서 지정한 출발·경로·기지를 그대로 쓴다(map_v2에는 지정이 없어 맵 에디터로 출발 (-10,1)·기지 (11,-1)·경로를 넣음). 적은 맵 밖이 아니라 출발 칸에서 나온다. 로봇 배치 구역과 카메라도 새 맵에 맞췄다. 튜토리얼의 길·배치 구역·코어 체력 강조도 새 맵을 따른다.
- 씬에 맵이 하나라 현재는 2·3스테이지도 같은 맵이다.
- 길이 길어져 적이 코어에 닿기까지 시간이 늘었다. 웨이브 시간·적 수 밸런스는 다시 보지 않았다.
