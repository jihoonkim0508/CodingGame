## 8. 맵 교체(map_v2)

- 스테이지 1 맵을 받은 `map_v2`로 바꿨다(`Stage01_v2.prefab`). 길이 더 길어졌다(37칸, 꺾임 8번).
- 적 경로와 코어 위치는 맵 에디터에서 지정한 출발·경로·기지를 그대로 쓴다(map_v2에는 지정이 없어 맵 에디터로 출발 (-10,1)·기지 (11,-1)·경로를 넣음). 적은 맵 밖이 아니라 출발 칸에서 나온다. 로봇 배치 구역과 카메라도 새 맵에 맞췄다. 튜토리얼의 길·배치 구역·코어 체력 강조도 새 맵을 따른다.
- 씬에 맵이 하나라 현재는 2·3스테이지도 같은 맵이다.
- 길이 길어져 적이 코어에 닿기까지 시간이 늘었다. 웨이브 시간·적 수 밸런스는 다시 보지 않았다.

| 공격 동작 속도 | 공격 동작이 다음 공격 전에 끝나도록 빨리 재생한다. 전사형: 간격 0.8초, 동작 1초 → 0.72초(1.39배). 사격형: 간격 1.2초, 동작 0.8초 그대로 |
| 레이저 시작점 | 사격형 레이저는 ShotRobot 포신(Cannon) 끝의 발사구에서 나간다 |
| 원거리 투사체 | 사격형 공격이 Stylized Projectile Pack의 파란 레이저(Laser_Blue_Small)로 바뀌었다: 발사구 섬광 → 적까지 날아가는 탄(초속 30) → 도착 시 착탄 이펙트. 버프·스턴 빔은 그대로 |
| 원거리 피해 시점 | 사격형 피해는 탄이 도착할 때 들어간다(발사 시점 아님). 탄 속도 초당 15칸(Shooter 데이터 projectileSpeed 4 → 15): 사거리 끝 5.5칸이면 약 0.37초. 탄은 발사 순간의 적 위치로 날아가고, 도착하면 그 적을 맞힌다. 날아가는 동안 적이 죽거나 사라지면 피해는 없다 |
| 근접 이펙트 중심 | 베기 이펙트의 원호 중심이 로봇 위치에 오도록 옮겼다(전에는 로봇 앞 약 1.3칸이 중심). 원호 바깥 끝이 사거리와 같다 |
| 근접 이펙트 방향·피해 시점 | 베기 이펙트를 좌우 반전해 검과 같은 방향(위에서 볼 때 시계 방향)으로 돌게 하고, 이펙트 전체의 중심이 적을 향하게 돌렸다. 피해는 검이 정면을 지나는 순간(공격 간격의 40% 뒤, 지금 0.32초)에 들어간다. 베기 이펙트의 검은 돌 조각(Stones)은 껐다 |

## 21. 1-1~1-4 실제 빌드 플레이 테스트 (마우스·키보드 조작)

빌드한 게임 창을 실제 마우스 드래그와 키보드 입력으로 1-1부터 1-4 끝까지 진행했다.

| 항목 | 처리 |
| --- | --- |
| 1-2: 변수 이름을 `enemy` 대신 `target`으로 | 통과 확인(이전 이슈 해결 상태) |
| 1-3 B02: 이름(`target`, `dist`)·줄 순서를 바꿔서 | 통과 확인 |
| 1-3 C03: 조건식을 `dist <= my_attack_range()`처럼 다른 이름으로 | 막혀 있었음 → 고침. 앞 단계에서 만든 코드의 변수 이름과 짝지어 판정한다 |
| 1-4 C04: `attack_range` 줄을 `enemy_distance`와 `if` 사이에 끼우기 | 블록이 사이에 끼워지지 않고 if 위에 겹쳐 놓였음 → 고침. 줄 사이에 놓으면 끼워진다. 안내 화살표도 if 위가 아니라 두 줄 사이를 가리킨다 |
| 1-4 전투: 3배속에서 전투 대사를 넘기기 전에 웨이브가 끝나면 | 지난 전투 대사와 사거리 강조가 보상 창 위에 늦게 떴음 → 고침. 웨이브가 끝나면 남은 전투 대사는 건너뛰고 클리어 대사로 간다 |
| 힌트 창 | 긴 줄(`enemy.distance(get_my_pos())`)이 오른쪽에서 잘렸음 → 글자 크기가 자동으로 줄어든다(18 → 최소 12) |
| 하단 오류 안내 | 전사형인데 예시가 `attack(enemy)`였음 → 해당 명령 이름(`slash(enemy)`)으로 |
| 피해 시점 변경에 맞춘 검사 | 사격형(도착 시)·전사형(검이 지날 때) 피해에 맞게 헤드리스 검사를 고쳤다 |

**확인 요청**
- 1-4에서 두 번째 전사형을 길에서 먼 곳에 놓으면 공격하지 못하고 적 1마리가 기지에 닿는다(기지 12 → 10). 배치 위치를 안내할지.
- 1-1 보상 창 안쪽 오른쪽에 세로 청록색 선이 보인다(스크롤 막대로 보임).
