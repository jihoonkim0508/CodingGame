## 8. 맵 교체(map_v2)

- 스테이지 1 맵을 받은 `map_v2`로 바꿨다(`Stage01_v2.prefab`). 길이 더 길어졌다(37칸, 꺾임 8번).
- 적 경로와 코어 위치는 맵 에디터에서 지정한 출발·경로·기지를 그대로 쓴다(map_v2에는 지정이 없어 맵 에디터로 출발 (-10,1)·기지 (11,-1)·경로를 넣음). 적은 맵 밖이 아니라 출발 칸에서 나온다. 로봇 배치 구역과 카메라도 새 맵에 맞췄다. 튜토리얼의 길·배치 구역·코어 체력 강조도 새 맵을 따른다.
- 씬에 맵이 하나라 현재는 2·3스테이지도 같은 맵이다.
- 길이 길어져 적이 코어에 닿기까지 시간이 늘었다. 웨이브 시간·적 수 밸런스는 다시 보지 않았다.

| 첫 배치 때 길 빨강·배치 가능 영역 흰색 | 로봇을 고른 뒤 놓기 전까지 바닥은 흰색, 길은 빨강. 놓거나 취소하면 원래 색 |
| 대사 속도 | 타이핑 속도 초당 30자 |
| 행동 없는 대사는 가운데 | 정비 단계에서 행동·강조 대상이 없는 대사는 화면 가운데에 조금 크게(흑백 처리 없음). 전투·보상 중 대사와 코드 편집기가 열린 동안의 대사는 아래 그대로(가운데로 오면 코드와 미리보기를 가림) |
| 변수·조건·반복 소개 때 강조 | 대사의 "변수, 조건문, 조건식, 반복문, 점(.)"을 굵은 노랑으로 |
| 로봇 선택 범위를 위로 | 로봇 발밑만이 아니라 몸 전체(머리 높이까지)를 클릭해도 선택됨 |
| 배치 블록 안에 들어오면 배치 | 블록 스냅을 오른쪽에서도 되게 한 작업(이전 반영분) |
| 버그: 튜토리얼 중 변수명 변경 안 됨 | 확인 불가. 선언 블록에서 이름을 바꾸면 사용처와 프로그램이 함께 바뀜. 비슷한 경우로, 사용처만 선언되지 않은 이름으로 바꾸면 경고 없이 이전 코드가 계속 실행됨. 재현 순서를 받으면 다시 확인 |
| 배속 3배 | 배속 버튼이 1x → 2x → 3x 순환 |
| 근접 공격 이펙트 안 보임 | 원인: 베기 이펙트가 3배 빠르게 재생돼 0.2초 만에 사라짐. 정상 속도로 재생 |
| 보상을 글 대신 블록 이미지로 | 웨이브 보상 창에 받은 블록을 편집기와 같은 모양으로 보여 주고 옆에 개수(x1) |
| 점 연산자 소개: 스킵 불가, 2초 뒤 자동 진행 | 1-2 B04 ~ B07은 다음 버튼이 없고, 글자가 다 나오고 2초 뒤 저절로 넘어감 |
| 1-2 C06 "힌트를 통해…"에서 다음 누르면 강조 해제 | C06에서 다음을 누르면 어둡게·테두리·화살표가 걷히고, 코드를 완성하면 진행 |
| 경고 카드 1초 간격, 하나씩 흔들림 | 1-1 A01 카드가 1초 간격으로 한 장씩 꽂히고, 꽂힐 때마다 화면이 살짝 흔들림. 경고 띠는 마지막 카드 뒤에 켜짐 |
| 1-1 E09 보상 수령 버튼이 대사창에 가려짐(플레이 테스트에서 발견) | E09 대사창을 위쪽으로 옮김(E03 전투 시작과 같은 방식) |
| 스크린샷: D04 화살표가 1번 줄을 가림 | 코드 줄 안의 빈칸을 가리킬 때도 화살표가 아래에서 가리킴 |
| 스테이지 선택 화면 진입 안내 | 들어갈 수 있는 첫 스테이지 위에 "여기를 클릭!"과 통통 튀는 화살표 |

- 길 강조의 이동 방향 화살표는 길이 다 그려진 뒤에 나온다.
- 보상 창에서 편집기에 아직 없는 블록은 이름으로 표시된다.

**확인 요청**: 시안 테두리 색, 가운데 대사 크기, 길이 그려지는 속도(1.2초), 스테이지 선택 안내 문구. 배치할 수 있는 자리의 사거리 원도 빨강이라, 배치 중 빨간 길(배치 불가)과 색이 겹친다.
