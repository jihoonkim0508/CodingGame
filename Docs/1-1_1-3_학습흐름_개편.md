| 1-4 | 조건문 자유 플레이 | 이번에는 미구현. 기존 데이터 보존 |

1-2는 새 전사 1대와 저장·적 찾기·변수 사용 블록을 지급한다. 1-1에서 받은 베기 보상을 새 로봇에 사용할 수 있다. 기존 로봇 코드는 지우지 않으며, 새 로봇 코딩·기존 코드 수정·변수 이름 선택은 플레이어에게 맡긴다. 편집기 방문과 정답 코드 제출을 강제하지 않고, 미완성 상태에서도 편집기를 닫을 수 있다. 힌트는 선택 사항이다.

1-3은 ‘비가 오면 우산을 쓴다’로 조건과 행동을 설명한다. 조건 없는 베기가 먼저 온 적 한 명을 맞히는 미리보기를 보여 준다. 처음 로봇에 적 찾기·거리 저장 두 줄을 제공한다고 먼저 알리고, 해당 로봇의 코드만 실습용으로 준비한다. 거리 계산의 세부 문법을 한꺼번에 조립시키지 않고 조건문에 집중한다. 다른 로봇의 프로그램은 유지한다.

비교 기호, 왼쪽 변수, 오른쪽 숫자 `2.5`, if 안쪽 행동을 각각 직접 조립한다. 기본 사거리 3.2보다 가까워질 때까지 기다렸다가 베면 두 적이 함께 맞는다. 참은 안쪽 실행, 거짓은 건너뜀으로 설명한다. 사거리 밖에서 대기하는 기존 로봇 동작을 조건문만의 새로운 효과라고 설명하지 않는다.

## 1-1 전투 조작·코어 피해 추가

- 1-1은 세 마리 모두 기존 기본 잡몹 `TutorialError`의 외형을 쓴다. 앞의 두 마리는 기본 수치이고, 마지막 한 마리의 등장 수치만 체력 500·이동 속도 1.6으로 강화했다. 코어 도달 피해는 1이다. 보스 자산과 1-5 보스의 수치는 바꾸지 않았다. 1스테이지 웨이브 제한 시간은 120초다.
- 첫 처치 뒤 설명 동안 전투를 0.2배속으로 느리게 보여 주고 속도 표시도 `0.2x`로 바뀐다. 그 상태에서 일시정지 버튼을 눌러 완전히 멈춘 모습과 비교하고, 계속을 누르면 보통 속도 `1x`로 돌아온다. 이어 2배속 버튼을 체험한다. 강한 적이 코어에 도착하면 실제 코어 체력 12→11을 강조한다.
- `dotnet build Assembly-CSharp-Editor.csproj`: 오류 0개. `dotnet run --project Tests/TutorialLessons/TutorialLessons.Check.csproj`: 기본 적 2명 처치·강한 적 1명 누출·코어 11/12·일시정지 시 전투 시간 정지 통과.
- Unity 6000.3.21f1의 별도 임시 프로젝트 복사본에서 실제 씬 Play 모드 자동 진행 검사를 완료했다. 1-1 종료 시 일반 적 2명 처치·강한 적 1명 누출·코어 11/12·생존 적 0명, 1-2 종료 시 누적 4명 처치·코어 11/12, 1-3 종료 시 누적 6명 처치·코어 11/12였다. 세 웨이브의 제한 시간 초과는 없었고 1-4 입구까지 도달했다.
- 일시정지·계속 버튼을 실제 HUD의 클릭 이벤트로 실행해 전투 상태 변화를 확인했고, 배속 버튼 클릭 뒤 2x를 확인했다. 전 대사의 텍스트 넘침과 편집기 강조 위치 누락도 자동 검사에서 발견되지 않았다. 이 검사는 사람의 마우스 조작과 실제 초보자 이해도 평가는 포함하지 않는다.
- 다음 검사에서는 1-2 자유 플레이 중 중앙 상단 목표 영역이 활성화되고 목표 문구가 들어가는지 검증했다.
- 목표 카드는 읽기 쉽도록 글자 밝기를 유지하고, 배경의 밝기 변화·2픽셀 상하 이동·0.4% 확대만 3.6초 주기로 반복한다. 전투 배속이나 일시정지와 관계없이 일정한 속도로 움직인다.

## 발견한 문제와 조치

- 편집기를 열 때 미리보기를 닫아 두면 나중에 명중을 기다리는 단계가 멈췄다. 1-3 편집기 진입 때 미리보기를 준비하고, 조립 중에는 실행을 멈추고 완성 후 실행하도록 수정했다. 수정 후 전체 통합 검사 통과.
- 직접 마우스로 if 안쪽 빈칸을 누르면 바깥 작업 영역이 선택됐다. 배치된 블록의 Body 배경이 클릭을 받도록 바인딩을 수정하고, 안내 화살표는 실제 선택 가능한 빈칸의 왼쪽 시작 영역을 가리키게 했다. 목록의 블록은 기존처럼 클릭하여 추가할 수 있다.
- 적이 미리보기 시작 지점에 너무 가까우면 첫 공격의 차이가 흐려졌다. 1-3 미리보기만 시작 위치를 뒤로 옮기고 적 두 명을 일정 간격으로 등장시켜 비교 장면을 안정화했다.
- 미리보기 타격이 대사 표시 도중 발생해도 결과를 현재 행동 단계가 받도록 수정했다.
- 조건이 거짓인 시도까지 제한 실행 횟수에 포함되어 실전에서 두 적을 놓쳤다. 공격이 실행된 호출만 횟수에 포함하고, 조건이 거짓일 때는 짧게 기다렸다가 다시 확인하도록 수정했다. 수정 후 1-3 단독 검증에서 코어 12/12·2명 처치를 확인했다. 1-1에 강한 적을 추가한 뒤 전체 검증에서는 코어 11/12·누적 6명 처치를 확인했다.

## 다시 확인하기

Play 종료 후 **Tools > Develop > Apply Beginner Lessons 1-1 to 1-3**으로 세 시퀀스와 세 웨이브 보급·주제를 적용한다. 씬과 1-4 이후 데이터는 갱신하지 않는다.

**Verify Beginner Lessons 1-1 to 1-3**은 게임 진입점으로 통합 검사를 실행한다. **Preview Beginner Lesson 1-3**은 직접 조작할 수 있도록 1-3 도입을 연다. **Preview 1-3 Attack Slot**은 비교식까지 준비하고 if 안쪽 행동 칸부터 연다.

**Verify Beginner Lesson 1-3 Only**는 1-3만 빠르게 다시 검사한다. 전체 검증은 1-1의 코어 11/12와 1-3까지의 추가 피해 없음을 요구한다. 1-3 단독 검증은 코어 12/12와 최소 2명 처치를 요구한다.

자동 진행 검사는 실제 마우스·키보드 조작과 구별하며, 실제 초보자의 이해도나 모든 화면 비율까지 검증한 것은 아니다.
