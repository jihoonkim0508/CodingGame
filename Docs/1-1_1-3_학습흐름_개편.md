# Stage 1 학습 흐름 개편 — 1-3까지

2026-10-25 사용자 요청 반영 / Unity 6000.3.21f1 / `E:\up\CodingGame`

## 구현 범위

| 웨이브 | 역할 | 현재 적용 |
|---|---|---|
| 1-1 | 변수·게임 플레이 방법 소개 | 초보자용 42단계. 설치 전 A01~B02 기존 대사 유지 |
| 1-2 | 변수를 활용한 자유 플레이 | 짧은 목표·조작 안내 3개 후 자유 플레이, 종료·복습·보상까지 총 6단계 |
| 1-3 | 조건문 소개 | 기초 코드 설명 → 비교식 조립 → if 안쪽 행동 → 미리보기·전투·복습, 총 32단계 |
| 1-4 | 조건문 자유 플레이 | 이번에는 미구현. 기존 데이터 보존 |
| 1-5 | 변수·조건문 활용 플레이 | 이번에는 미구현. 기존 데이터 보존 |

1-2는 새 전사 1대와 저장·적 찾기·변수 사용 블록을 지급한다. 1-1에서 받은 베기 보상을 새 로봇에 사용할 수 있다. 기존 로봇 코드는 지우지 않으며, 새 로봇 코딩·기존 코드 수정·변수 이름 선택은 플레이어에게 맡긴다. 편집기 방문과 정답 코드 제출을 강제하지 않고, 미완성 상태에서도 편집기를 닫을 수 있다. 힌트는 선택 사항이다.

1-3은 ‘비가 오면 우산을 쓴다’로 조건과 행동을 설명한다. 처음 로봇에 적 찾기·거리 저장 두 줄을 제공한다고 먼저 알리고, 해당 로봇의 코드만 실습용으로 준비한다. 거리 계산의 세부 문법을 한꺼번에 조립시키지 않고 조건문에 집중한다. 다른 로봇의 프로그램은 유지한다.

비교 기호, 왼쪽 변수, 오른쪽 사거리, if 안쪽 행동을 각각 직접 조립한다. 참은 안쪽 실행, 거짓은 건너뜀으로 설명한다. 사거리 밖에서 대기하는 기존 로봇 동작을 조건문만의 새로운 효과라고 설명하지 않는다.

## 발견한 문제와 조치

- 편집기를 열 때 미리보기를 닫아 두면 나중에 명중을 기다리는 단계가 멈췄다. 1-3 편집기 진입 때 미리보기를 준비하고, 조립 중에는 실행을 멈추고 완성 후 실행하도록 수정했다. 수정 후 전체 통합 검사 통과.
- 직접 마우스로 if 안쪽 빈칸을 누르면 바깥 작업 영역이 선택됐다. 배치된 블록의 Body 배경이 클릭을 받도록 바인딩을 수정하고, 안내 화살표는 실제 선택 가능한 빈칸의 왼쪽 시작 영역을 가리키게 했다. 목록의 블록은 기존처럼 클릭하여 추가할 수 있다.
