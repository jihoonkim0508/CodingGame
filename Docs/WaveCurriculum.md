# 스테이지별 보급·보상

기본 인벤토리는 비워 두고 준비 단계에서 학습에 필요한 물품만 한 번 지급합니다. 보상은 웨이브당 블록 1개입니다. 총 지급량은 로봇 8대, 준비 블록 41개, 보상 블록 25개입니다. 블록은 재사용하며 로봇 회수 시 사용 블록도 반환됩니다.

동시 설치는 6대, 버프형은 최대 1대입니다. 1스테이지 로봇 지급은 원거리 2대와 전사형 1대이므로 2스테이지 첫 유틸형을 바로 추가할 수 있습니다.

학습 주제는 CodinggameDoc.pdf 4~5쪽 기준입니다. 원문은 4스테이지까지이며 5스테이지는 종합 응용입니다. Attack() 학습을 위해 원거리 로봇을 먼저 지급합니다.

## 몬스터 수치

기본 체력 55, 이동 속도 1.65. 공격력은 일반 10, 빠른 적 8, 중장갑 20입니다. 스테이지·웨이브·유형별 기존 배율은 추가 적용합니다.

## 진단 로그

Unity Editor와 Development Build에서 [Defense] 로그를 남깁니다. 스테이지·웨이브·전투 상태·설치 수·기지 체력, 설치 실패 이유, 전투 시작 시 적 수치, 보상 수령 시 결과를 기록합니다. 프레임마다 반복 출력하지 않습니다. Unity Console에서 [Defense]로 검색하거나 Windows의 %LOCALAPPDATA%/Unity/Editor/Editor.log를 확인하세요.

## 검증

Tests/Unity/CampaignFiveStagesCheck.cs: 실제 씬의 25웨이브 진행과 보상·스테이지 전환을 검사합니다.
Tests/Unity/PlacementFeedbackCheck.cs: 2스테이지 첫 유틸형 설치, 6대 제한, 실패 알림·페이드아웃, 등장하지 않는 적 숨김과 설명창 크기를 검사합니다. Unity Play Mode에서 Unity CLI로 실행합니다.

## 로봇 조작

해금 전 로봇은 하단 선택칸과 인벤토리에서 숨깁니다. 해금한 로봇은 재고가 0이어도 표시합니다. 배치한 로봇을 클릭하면 왼쪽 위 레벨업, 오른쪽 위 개발, 아래 회수 버튼이 표시됩니다. 개발을 누르면 코드 편집을 시작하고 왼쪽 위에서 코드를 미리 봅니다. 미리보기 영역은 좌클릭 드래그로 이동하고 휠로 확대·축소합니다.

개발자 모드의 전체 추가 버튼은 누를 때마다 각 로봇 10대와 모든 블록 50개를 기존 보유량에 더합니다.

Tests/Unity/RobotInteractionCheck.cs는 선택 메뉴, 레벨업 비용, 개발·회수, 미리보기 조작, 개발자 전체 지급을 검사합니다.

## 변수 참조와 적 정보

변수 선언 블록으로 값을 저장하고, 하나의 variable 참조 블록에 사용할 이름을 직접 입력합니다. 적 변수 이름 끝에 점을 입력하면 get_distance(x, y)를 선택할 수 있습니다. 점을 삭제하면 드롭다운과 인자 슬롯이 숨겨집니다. 미선언 이름은 오류로 표시하며 편집 중인 블록을 삭제하지 않습니다.

적 정보 센서 3종은 제거했습니다. 2스테이지부터 enemy = get_nearest_enemy()로 적을 저장하고 enemy.get_distance(x, y)로 거리를 비교합니다. 저장한 적이 사라지면 거리는 무한대입니다.

Tests/Unity/VariableInputCheck.cs는 선택 사거리, 단일 변수 참조, 직접 입력, 점 추가·삭제, 거리 메서드 실행 코드 생성, 수량 예약과 실행 취소·다시 실행을 검사합니다.
